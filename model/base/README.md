# Local base model

Large files in this directory are excluded from Git; see the parent [README](../README.md).
The maintainer downloaded `google/gemma-4/Other/gemma-4-31b-it-qat-w4a16-ct/2`
into `gemma-4-31b-it-qat-w4a16-ct-v2/`: eight files including weights, tokenizer,
configuration, and chat template, totaling about 21.70 GiB.

Offline loading and one-task patch generation passed in an allocated job; see
[runtime evidence](../../resource/manifests/hpc-smoke.json). Training and a full local
benchmark have not been validated. Preserve the original model README and follow its usage and redistribution terms.
