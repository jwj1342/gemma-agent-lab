# University marks

These marks identify the authors' affiliations. They remain the property of
their respective institutions and are not presented as team-created artwork.
Retrieved on October 5, 2026, except for the Alberta asset already supplied in
the user's Overleaf project.

| File | Institution | Provenance and display treatment |
| --- | --- | --- |
| `alberta.png` | University of Alberta | Existing Overleaf asset `logo/University_of_Alberta_Logo_(2021).svg.png`, retained byte-for-byte from remote commit `ac488738b9f7cee10e33b4eedfd8f5145f0d7288`. LaTeX displays only the left 22.5% of the image, selecting the full shield and excluding the horizontal wordmark. The shield is scaled proportionally to 6 mm high and centered in a 6 mm-wide slot. |
| `hdu-source.svg` | Hangzhou Dianzi University | Unchanged [official website header artwork](https://www.hdu.edu.cn/_upload/tpl/02/12/530/template530/images/logo_main.svg), linked from the [official identity page](https://www.hdu.edu.cn/666/list.htm). |
| `hdu.svg`, `hdu.pdf` | Hangzhou Dianzi University | The SVG viewport selects the square seal at the left of the official lockup; artwork paths and colors are unchanged. The PDF is a vector conversion using `rsvg-convert`. |
| `westlake.png` | Westlake University | `Westlake_University_Logo/Westlake Logo.png` from the [official VIS logo ZIP](https://en.westlake.edu.cn/about/VIS/202308/P020231201608947610203.zip), linked by the [English visual identity page](https://en.westlake.edu.cn/about/VIS/). Unchanged artwork. |
| `tongji.png` | Tongji University | [Official seal PNG](https://www.tongji.edu.cn/images/badge.png), used on the [university identity page](https://www.tongji.edu.cn/xxgk1/xxbs1.htm). Unchanged artwork. |
| `fudan.png` | Fudan University | Original seal artwork sheet from the [official identity archive](https://www.fudan.edu.cn/_upload/article/files/bf/08/728cadcb4c309a684ce1ea34a913/d63c65eb-0561-418f-8c63-95aa4be86ec0.rar), linked by the [identity downloads page](https://www.fudan.edu.cn/fdbsxz/list.htm). The source file is unchanged; LaTeX clips the sheet to its blue seal for display. |

All marks are scaled proportionally. Chinese lettering that forms part of an
authentic mark is retained; the presentation's authored text is English.
