Use one relevant resource when the current source evidence leaves uncertainty:

- `resources/defaults.md`: distinguish missing values from valid falsey values.
- `resources/contracts.md`: preserve caller/callee behavior and boundary cases.
- `resources/graph.md`: navigate with graph evidence and source confirmation.
- `resources/verification.md`: interpret a reproduction and a regression check.

These guides are team-authored patterns, not solutions to benchmark tasks. Load
only the relevant guide. Derive concrete paths, symbols and edits from the current
repository. All model calls continue to use the required competition model.
