# 🐈‍⬛ Agentic · Counterexample Lab | v1

**Method Summary.** A single coding agent converts explicit issue requirements into small executable counterexamples. It freezes up to three probes before editing, repairs the repository source, and replays the same assertions in fresh processes. Boundary and regression probes expose incomplete repairs. The nearest existing tests remain an additional local check.

**Hypothesis.** Fixed before/after expectations may help Gemma distinguish a complete behavioral repair from a plausible patch. Generated assertions are fallible: every expectation must come from the issue or an existing API/test. Probe success does not predict hidden-test success.

| Design | Choice |
|---|---|
| Model | Required `gemma-4-31b-it-qat-w4a16-ct`; no adapter |
| Agent | One coder with six built-in tools and one sandbox skill |
| Probe budget | Maximum three probes, 8-second default and 12-second cap each |
| Issue budget | Five minutes, 100 tool calls; final time reserved for submission |
| Submission | New prompts, configuration and Python skill; no previous archive embedded |

This notebook is a standalone English experiment. Packaging runs offline on CPU; a separate GPU pilot evaluates the same payload on public development tasks. No leaderboard improvement or rank is claimed. The competition applies patches to fresh repositories and scores passed validation tests: [official evaluation](https://www.kaggle.com/competitions/gemma-4-developer-agent/overview).

**Execution contract.** `probe_issue` must fail by assertion before editing to establish reproduction. Missing imports, setup errors and timeouts are recorded separately. The after phase accepts no replacement code and checks the frozen code hash. `VERIFIED_BY_PROBES` requires original reproduction followed by all frozen probes passing. Scratch files stay outside the repository.

**Graceful degradation.** If a probe is impractical or fails to run, the agent continues its source repair and nearest existing tests. If package validation fails, a newly authored minimal coder configuration provides a schema-valid recovery output. No prior submission bytes are included.

import ast, hashlib, io, posixpath, re, zipfile
from pathlib import Path
import yaml

MODEL = "gemma-4-31b-it-qat-w4a16-ct"
class IncludeLoader(yaml.SafeLoader):
    pass
IncludeLoader.add_constructor("!include", lambda loader, node: loader.construct_scalar(node))

def sha(data):
    return hashlib.sha256(data).hexdigest()

def validate(files):
    assert "agent.yaml" in files and len(files) <= 20
    assert sum(len(s.encode("utf-8")) for s in files.values()) < 3 * 1024**3
    for name, source in files.items():
        assert name and not name.startswith(("/", "\\")) and ".." not in name.split("/")
        assert ":" not in name and "\\" not in name and Path(name).suffix in {".yaml", ".md", ".py"}
        assert isinstance(source, str) and source.strip()
        if name.endswith(".py"):
            ast.parse(source, filename=name)
        if name.endswith(".yaml"):
            yaml.load(source, Loader=IncludeLoader)
            for ref in re.findall(r"!include\s+([^\s]+)", source):
                assert posixpath.normpath(posixpath.join(posixpath.dirname(name), ref)) in files
    agent = yaml.load(files["agent.yaml"], Loader=IncludeLoader)
    assert agent["model"] == MODEL and agent["name"] == "agentic_counterexample_lab"
    assert agent["tools"] == ["run_command", "read_file", "edit_file", "write_file", "get_status", "submit_patch"]
    for skill in agent.get("skills", []):
        manifest = files[skill + "/SKILL.md"]
        assert yaml.safe_load(manifest.split("---", 2)[1])["name"] == skill.rsplit("/", 1)[-1]
    limits = yaml.safe_load(files["eval_config.yaml"])["evaluation"]
    assert 0 < limits["timeout_seconds"] <= 60 and 0 < limits["max_time_minutes"] <= 5
    assert 0 < limits["max_tool_calls"] <= 100 and 0 < limits["max_turns"] <= 250

def pack(files):
    validate(files)
    stream = io.BytesIO()
    with zipfile.ZipFile(stream, "w") as archive:
        for name, source in sorted(files.items()):
            info = zipfile.ZipInfo(name, date_time=(1980, 1, 1, 0, 0, 0))
            info.compress_type = zipfile.ZIP_DEFLATED
            info.create_system = 3
            info.external_attr = 0o644 << 16
            archive.writestr(info, source.encode("utf-8"))
    result = stream.getvalue()
    with zipfile.ZipFile(io.BytesIO(result)) as archive:
        assert archive.testzip() is None and len(archive.namelist()) == len(set(archive.namelist()))
        assert {n: archive.read(n).decode("utf-8") for n in archive.namelist()} == files
    return result

def select_bundle(candidate, minimal, force_minimal=False):
    errors = []
    if not force_minimal:
        try:
            return pack(candidate), "counterexample challenger", errors
        except Exception as error:
            errors.append(type(error).__name__ + ": " + str(error))
    return pack(minimal), "minimal recovery", errors
