#  Gemma-4 Developer Agent: Advanced Multi-Agent Architecture

##  Executive System Overview
This production-grade notebook implements a fully compliant, high-efficiency **Google Agent Development Kit (ADK)** architecture customized for the **Gemma-4 Developer Agent Competition**. 

To tackle the extreme context window saturation and reasoning loops common in SWE-bench regressions, this system abandons generic brute-force file crawling. Instead, it deploys an isolated **Multi-Agent Orchestration Loop** connected to **Built-in Call Graphs** and **Fine-tuned PEFT LoRA Adapters**.

---

##  Core Architecture Blueprint

The generated `submission.zip` is programmatically structured as follows:

```text
submission.zip
├── agent.yaml                       # Root Coder Agent (Orchestrates workflow via main_lora)
├── eval_config.yaml                 # Runtime constraints (Optimized to 15-min per task limit)
├── configs/
│   └── sampling.yaml                # Ultra-low temperature (0.05) deterministic parameters
├── prompts/
│   └── system.md                    # Thinking-budget guided master task delegation directives
├── sub_agents/
│   └── code_analyzer.yaml           # Read-only Graph crawler & File explorer (via tool_lora)
├── adapters/
│   ├── main_lora/                   # Specialized PEFT weights for accurate Search/Replace patches
│   └── tool_lora/                   # Specialized PEFT weights for AST hierarchy comprehension
└── skills/
    └── repo_navigation/             # Infuses domain knowledge playbooks directly into the container
        ├── SKILL.md                 # Skill manifest entry point
        └── resources/
            └── domains.md           # Quick-lookup rule book for FastAPI, Requests, and HTTPX
```

---

##  Strategic Defense Mechanisms Embedded

1. **Anti-Timeout Submission Guard (`IS_KAGGLE_SUBMITTING`):** Isolates all internal smoke-testing, git initializations, and local test runners. If Kaggle triggers a static private evaluation re-run, these scripts drop out instantly to prevent the notorious **26-32 seconds instant-abort crash**.
2. **Context Window Shielding (`skip_summarization: true`):** The Root Agent delegates heavy text indexing to the `code_analyzer` sub-agent. Raw file dumps and terminal clutter are trapped inside the sub-agent session, keeping the master context window clean, deterministic, and highly focused on generating patches.
3. **Graph-First Localization Strategy:** Enforces the immediate utilization of platform native tools (`search_similar_code`, `get_code_neighbors`) over expensive text grepping. It performs localized code surgery, conserving significant time and token budget across the massive 12-hour evaluation ceiling.

import numpy as np
import json
from pathlib import Path

def find_top_buggy_candidates(task_id, query_vector=None, embeddings_dir="/kaggle/input/competitions/gemma-4-developer-agent/embeddings"):
    """
    Computes the Cosine Similarity between a query vector (from the bug report) 
    and the pre-computed embedding matrix of the repository nodes.
    
    Parameters:
    -----------
    task_id : str
        The unique instance identifier (e.g., 'fastapi_14791')
    query_vector : np.ndarray, optional
        A 1D float array representing the embedded bug description.
        If None, a mock fallback execution is triggered for demonstration.
    embeddings_dir : str
        The directory mapping all target .npz matrix binary archives.
    """
    archive_path = Path(embeddings_dir) / f"{task_id}.npz"
    
    print(f"🔍 Analyzing Embedding Node Matrix for Task ID: {task_id}...")
    
    if not archive_path.is_file():
        print(f"⚠️ Vector archive file not found at: {archive_path}")
        return []
        
    try:
        # Load the compressed numpy structural dataset
        data = np.load(archive_path, allow_pickle=True)
        
        # Check standard Google ADK output array signatures
        if 'nodes' not in data or 'embeddings' not in data:
            print("❌ Invalid archive schema: Missing 'nodes' or 'embeddings' arrays.")
            return []
            
        nodes = data['nodes']          # Array of source code structural entry points (strings)
        embeddings = data['embeddings'] # 2D Matrix of dimension weights (shape: Num_Nodes x Dimensions)
        
        print(f"   ↳ Codebase Profile: Detected {len(nodes)} distinct functional nodes inside the matrix.")
        
        # Mock fallback handler if your pipeline hasn't called the token encoder API yet
        if query_vector is None:
            print("   💡 No query vector supplied. Defaulting to exact structural component retrieval.")
            # Yield the first 3 components as high-probability targets
            results = [(nodes[i], 1.0) for i in range(min(3, len(nodes)))]
            return results
            
        # Ensure query vector dimensions match the repository density dimension matrix
        if query_vector.shape[0] != embeddings.shape[1]:
            print(f"❌ Dimension mismatch: Query is {query_vector.shape[0]}, matrix targets expect {embeddings.shape[1]}")
            return []
            
        # --- VECTORIZED COSINE SIMILARITY MATH (NO FOR-LOOPS) ---
        # Formula: (A dot B) / (norm(A) * norm(B))
        dot_product = np.dot(embeddings, query_vector)
        matrix_norms = np.linalg.norm(embeddings, axis=1)
        query_norm = np.linalg.norm(query_vector)
        
        # Prevent runtime division by zero warnings
        matrix_norms = np.where(matrix_norms == 0, 1e-9, matrix_norms)
        if query_norm == 0: 
            query_norm = 1e-9
            
        cosine_scores = dot_product / (matrix_norms * query_norm)
        
        # Extract the index references sorted by highest score descending
        top_indices = np.argsort(cosine_scores)[::-1][:3]
        
        # Build clean structural response models
        ranked_candidates = [(nodes[idx], float(cosine_scores[idx])) for idx in top_indices]
        
        print("🎯 Top 3 Graph-Augmented localized target components found:")
        for rank, (node_name, score) in enumerate(ranked_candidates, 1):
            print(f"  {rank}. Score [{score:.4f}] ➔ {node_name}")
            
        return ranked_candidates
        
    except Exception as e:
        print(f"❌ Technical breakdown parsing matrix arrays: {str(e)}")
        return []
