# CELL 0 markdown
# What the training data tells us about building the agent

**Competition:** Gemma 4 Developer Agent. An AI agent gets a bug report or feature request for a Python repository and has to change the code so that hidden tests pass.

**This notebook** studies the 129 training tasks to answer one practical question: *what should the agent do differently?*

## In one minute
1. **Searching with grep finds the right file far more often than the "smart" search tools.**
   - With grep, the file to fix shows up in the agent's view for **60%** of tasks.
   - With the similarity search, it does for **28%**; with the code graph, **29%**.
2. **The similarity search tool (`search_similar_code`) is risky.**
   - One answer is typically about 3,000 tokens, and the largest is 264,000 characters, far more than the model can hold.
   - It also only works when the issue names an exact function or class, which happens in about **40%** of tasks.
3. **Files are big, so the agent must read small pieces.**
   - About **1 in 7** files that need fixing are bigger than everything the model can hold at once.
   - In a third of tasks, the line to change is more than 300 lines into the file.
4. **The code graph misses a lot.**
   - It has no `async` functions (16% of tasks change one).
   - It has no imports or constants (about half of tasks change one).
5. **A quarter of tasks are feature requests, not bugs.** "Reproduce the bug first" doesn't work for those.
6. **The `hints_text` field is empty for every task**, so it's useless in the prompt.

## Words used here
| Word | Meaning |
|---|---|
| **task** | One issue (bug report or feature request) in one repository. |
| **official fix** | The real fix the maintainers made (the `patch` field). It tells us which file and lines needed changing. |
| **file to fix** | A file the official fix changes. |
| **grep** | Plain text search: "which files contain this word?" |
| **similarity search** | The `search_similar_code` tool. It finds code that "looks similar" to a named function or class. |
| **code graph** | A map of which functions call which (the `get_code_neighbors` tool). |
| **context** | Everything the model can hold in mind at once: 32,768 tokens, which is about 118,000 characters. |
| **token** | A chunk of text; here, about 3.6 characters. |

*Runtime: about 8–10 minutes on Kaggle CPU. Set the environment variable `N_TASKS=10` for a quick test.*

def parse_patch(patch):
    """Which files a diff changes, how many lines, and which original line numbers."""
    files, cur, old_ln = {}, None, 0
    for line in patch.splitlines():
        if line.startswith('--- '):
            continue
        if line.startswith('+++ '):
            path = line[4:].split('\t')[0]
            path = path[2:] if path.startswith(('a/', 'b/')) else path
            cur = files.setdefault(path, {'added': 0, 'removed': 0, 'old_lines': set(), 'new_file': False})
            continue
        m = re.match(r'@@ -(\d+)(?:,(\d+))? \+(\d+)(?:,(\d+))? @@', line)
        if m and cur is not None:
            old_ln = int(m.group(1))
            cur['new_file'] |= m.group(1) == '0' and m.group(2) == '0'
            continue
        if cur is None:
            continue
        if line.startswith('+'):
            cur['added'] += 1; cur['old_lines'].add(max(old_ln, 1))
        elif line.startswith('-'):
            cur['removed'] += 1; cur['old_lines'].add(old_ln); old_ln += 1
        else:
            old_ln += 1
    return files

def snapshot_py(iid):
    """All .py files of the repository before the fix: {path: text}."""
    files = {}
    with tarfile.open(DATA / 'snapshots' / f'{iid}.tgz', 'r:gz') as tf:
        for m in tf:
            if m.isfile() and m.name.endswith('.py') and m.size < 2_000_000:
                path = m.name[2:] if m.name.startswith('./') else m.name
                if '/.git/' not in f'/{path}' and not path.startswith(('.venv/', 'venv/')):
                    files[path] = tf.extractfile(m).read().decode('utf-8', 'replace')
    return files

def resource(kind, row, ext):
    """Graph/embedding file. On Kaggle each exists under two names, one of them empty."""
    for name in (row.instance_id, f'{row.repo_short}_{row.base_commit}'):
        p = DATA / kind / f'{name}.{ext}'
        if p.exists() and p.stat().st_size > 100:
            return p
    return None

def module_index(paths):
    """Python module name -> file path (graph names sometimes drop leading folders such as docs_src/)."""
    idx = {}
    for p in sorted(paths, key=len):
        parts = p[:-3].split('/')
        if parts[-1] == '__init__':
            parts = parts[:-1]
        for i in range(len(parts)):
            idx.setdefault('.'.join(parts[i:]), p)
    return idx

def node_file(node_id, midx):
    parts = node_id.split('.')
    for i in range(len(parts), 0, -1):
        if f := midx.get('.'.join(parts[:i])):
            return f
    return None

def enclosing_defs(src, lines):
    """For each changed line: the function/class it sits in ('<module>' if none), plus which of those are async."""
    try:
        tree = ast.parse(src)
    except SyntaxError:
        return {}, set()
    spans = []
    def walk(node, prefix):
        for ch in ast.iter_child_nodes(node):
            if isinstance(ch, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef)):
                start = min([ch.lineno] + [d.lineno for d in getattr(ch, 'decorator_list', [])])
                q = f'{prefix}{ch.name}'
                spans.append((start, ch.end_lineno, q, isinstance(ch, ast.AsyncFunctionDef)))
                walk(ch, q + '.')
    walk(tree, '')
    out, async_q = {}, set()
    for ln in lines:
        inner = [s for s in spans if s[0] <= ln <= s[1]]
        if inner:
            s = max(inner, key=lambda s: s[0])
            out[ln] = s[2]
            if s[3]:
                async_q.add(s[2])
        else:
            out[ln] = '<module>'
    return out, async_q

STOP = set('''the and for with from that this when then else none true false self args kwargs return import class def
async await type list dict str int bool object value values data name names file files test tests error errors issue
python fastapi rich requests httpx docs example examples version default param params option options'''.split())

def code_names(text, repo_words):
    """Code-like names in the issue (`backticked`, CamelCase, snake_case, dotted) that exist in the repo."""
    cands = set(re.findall(r'`([^`\n]{2,60})`', text))
    cands |= set(re.findall(r'\b([A-Z][a-z0-9]+(?:[A-Z][a-z0-9]+)+)\b', text))
    cands |= set(re.findall(r'\b([a-z_][a-z0-9]*_[a-z0-9_]+)\b', text))
    cands |= set(re.findall(r'\b([A-Za-z_]\w*(?:\.[A-Za-z_]\w*)+)\b', text))
    out = set()
    for c in cands:
        c = c.strip().strip('()').split('(')[0].lstrip('@.')
        if c.endswith('.py'):
            c = c[:-3].split('/')[-1]
        c = c.split('.')[-1] if '.' in c else c
        if len(c) >= 3 and c.lower() not in STOP and re.fullmatch(r'[A-Za-z_]\w*', c) and c in repo_words:
            out.add(c)
    return sorted(out)

def grep_search(files, words, targets):
    """Rank files by how often the words appear. Also: does a target file appear within the first
    5,000 characters of `grep -n <word>` output, i.e. what the agent actually gets to see?"""
    score, seen = Counter(), False
    for w in words:
        pat = re.compile(rf'\b{re.escape(w)}\b')
        shown = 0
        for path in sorted(files):
            n = len(pat.findall(files[path]))
            if n:
                score[path] += n
                for ln in [l for l in files[path].splitlines() if pat.search(l)][:n]:
                    shown += len(path) + len(ln) + 8
                    seen |= shown <= OUT_CAP and path in targets
    ranked = [p for p, _ in score.most_common()]
    return min((ranked.index(g) + 1 for g in targets if g in ranked), default=None), seen

T['fix'] = T.patch.map(parse_patch)
T['tests'] = T.test_patch.map(parse_patch)
present = {p.name for p in (DATA / 'snapshots').glob('*.tgz')}
rows, t0 = [], time.time()
for n, row in enumerate(T.itertuples()):
    if f'{row.instance_id}.tgz' not in present:
        continue
    files = snapshot_py(row.instance_id)
    fix_files = {p: f for p, f in row.fix.items() if p.endswith('.py') and not f['new_file'] and p in files}
    targets = {p for p in row.fix if p.endswith('.py')}
    midx = module_index(files)
    r = {'task': row.instance_id, 'repo': row.repo_short}

    # How big is the file to fix, and how deep is the line to change?
    first = [min(f['old_lines']) for f in fix_files.values() if f['old_lines']]
    r['file_tokens'] = max(len(files[p]) for p in fix_files) / CHARS_PER_TOKEN if fix_files else np.nan
    r['file_lines'] = max(len(files[p].splitlines()) for p in fix_files) if fix_files else np.nan
    r['reads_to_reach_change'] = max(math.ceil(l / READ_LINES) for l in first) if first else np.nan

    # Which functions/classes does the fix change? Any async? Any change outside functions?
    changed, changed_async, outside = set(), set(), False
    for p, f in fix_files.items():
        enc, asy = enclosing_defs(files[p], f['old_lines'])
        mod = p[:-3].replace('/', '.').removesuffix('.__init__')
        outside |= '<module>' in enc.values()
        changed |= {(mod, q) for q in enc.values() if q != '<module>'}
        changed_async |= {(mod, q) for q in asy}
    r['changed_functions'], r['changed_async'], r['change_outside_functions'] = len(changed), len(changed_async), outside

    # Code graph
    gpath = resource('graphs', row, 'json')
    G = json.load(open(gpath)) if gpath else {'nodes': [], 'edges': []}
    nodes = {nd['id']: nd.get('text', '') for nd in G['nodes']}
    adj = defaultdict(set)
    for e in G.get('edges', G.get('links', [])):
        adj[e['source']].add(e['target']); adj[e['target']].add(e['source'])
    r['graph_entries'] = len(nodes)
    r['graph_links'] = sum(len(v) for v in adj.values()) // 2
    r['share_unlinked'] = 1 - len(adj) / max(len(nodes), 1)

    def in_graph(mod, q):
        for i in range(mod.count('.') + 1):
            cand = '.'.join(mod.split('.')[i:]) + f'.{q}'
            if cand in nodes:
                return cand
        return None
    changed_in_graph = {in_graph(m, q) for m, q in changed} - {None}
    r['changed_in_graph'] = len(changed_in_graph)

    # Searching for the file to fix, using words from the issue
    df = Counter(w for t in files.values() for w in set(re.findall(r'[A-Za-z_]\w+', t)))
    names = code_names(row.problem_statement, df)
    rare = sorted({w for w in re.findall(r'\b[A-Za-z_]\w{3,}\b', row.problem_statement)
                   if w.lower() not in STOP and 0 < df.get(w, 0) <= max(2, 0.02 * len(files))} - set(names))
    r['issue_code_names'] = len(names)
    r['grep_rank'], r['grep_seen'] = grep_search(files, names, targets) if names else (None, False)
    r['grep_rank_more_words'], _ = grep_search(files, names + rare, targets) if names + rare else (None, False)
    r['file_name_match'] = any(Path(g).stem.lstrip('_') in {a.lower() for a in names} for g in targets)

    epath = resource('embeddings', row, 'npz')
    sim_rank, graph_hit, usable, answer_chars = None, False, 0, []
    if epath and nodes:
        z = np.load(epath)
        keys = [k[:-4] if k.endswith('.npy') else k for k in z.files]
        vecs = np.stack([z[k] for k in z.files]).astype(np.float32)
        vecs /= np.linalg.norm(vecs, axis=1, keepdims=True) + 1e-9
        kpos = {k: i for i, k in enumerate(keys)}
        i, j = np.random.default_rng(0).integers(0, len(keys), (2, 2000))
        pair = np.sum(vecs[i] * vecs[j], axis=1)
        r['random_similarity'], r['near_duplicates'] = float(pair.mean()), float((pair >= 0.99).mean())
        for a in names:
            # same lookup as the tool: exact name, else the first entry ending in ".<name>"
            hit = a if a in kpos else next((k for k in keys if k.endswith('.' + a)), None)
            if hit is None:
                continue
            usable += 1
            top = np.argsort(-(vecs @ vecs[kpos[hit]]))[:10]
            top_files = [node_file(keys[t], midx) for t in top]
            answer_chars.append(sum(len(nodes.get(keys[t], '')) for t in top))
            ranks = [top_files.index(g) + 1 for g in targets if g in top_files]
            if ranks:
                sim_rank = min(ranks + ([sim_rank] if sim_rank else []))
            graph_hit |= any(node_file(x, midx) in targets for x in adj.get(hit, set()) | {hit})
    r['similarity_usable'], r['similarity_rank'], r['graph_hit'] = usable > 0, sim_rank, graph_hit
    r['similarity_answer_chars'] = max(answer_chars) if answer_chars else np.nan
    rows.append(r)
    if n % 20 == 0:
        print(f'{n + 1}/{len(T)} tasks done ({time.time() - t0:.0f}s)', flush=True)

D = pd.DataFrame(rows)
D.to_csv(OUT / 'per_task.csv', index=False)
print(f'Finished {len(D)} tasks in {time.time() - t0:.0f}s. Per-task results saved to per_task.csv.')

# CELL 7 markdown
**How to read this:**
- **"Grep: file is in what the agent sees"** is the most realistic number. A grep result is cut after 5,000 characters, so this counts whether the file to fix is in the visible part.
- **"Similarity search usable at all"** is low because the tool only accepts an exact function or class name. If the issue doesn't name one, the tool can't be used.
- **"Issue has no code name"** marks the hard tasks. The agent has to search with ordinary words from the issue, or start from the tests.

**What we'll change:** tell the agent to grep the names in the issue first, piping through `| head` so the answer isn't cut, and then read the top file around the matching lines. Use the code graph only to find who calls a function, and drop the similarity search.

**What we'll change:**

FEATURE_WORDS = r'\b(add|adds|added|support|allow|new|introduce|implement|enable|option|feature)\b'
BUG_WORDS = r'\b(fix|fixes|fixed|bug|error|crash|incorrect|wrong|broken|regression|fails?|exception|traceback|issue)\b'

def kind(text):
    head = text.strip()[:300].lower()
    if head.startswith(('✨', '🎉', '➕')):
        return 'Feature'
    if head.startswith(('🐛', '🚑', '🩹')):
        return 'Bug fix'
    f, b = len(re.findall(FEATURE_WORDS, head)), len(re.findall(BUG_WORDS, head))
    return 'Feature' if f > b else 'Bug fix' if b > f else 'Unclear'

**Short answer: they usually add one or two new test functions, often bigger than the fix itself.**

T['new_test_functions'] = T.test_patch.map(lambda p: len(re.findall(r'^\+\s*(?:async\s+)?def (test_\w+)', p, re.M)))
T['test_lines'] = T.tests.map(lambda g: sum(f['added'] + f['removed'] for f in g.values()))
T['new_test_file'] = T.tests.map(lambda g: any(f['new_file'] for f in g.values()))
tests = T.groupby('repo_short')[['new_test_functions', 'test_lines', 'lines_changed']].median().astype(int)
tests['Tests go in a new file'] = T.groupby('repo_short').new_test_file.mean().map(pct)
tests.columns = ['New test functions', 'Test lines', 'Fix lines', 'Tests go in a new file']
tests.index.name = 'Repository'
display(tests)
print(f"The data has no list of which tests must pass (no FAIL_TO_PASS field): {'FAIL_TO_PASS' not in T.columns}")

fig, ax = plt.subplots(figsize=(6, 3.2))

# CELL 19 markdown
**What we'll change:** after editing, the agent should run the existing test file for the module it changed, plus a tiny check script of its own in `/tmp`. The hidden tests usually call the new or fixed behaviour directly, so the agent's own check should do the same.

## 6. Summary: what we'll change in the agent
| Finding | Change |
|---|---|
| Grep finds the file to fix most often | Prompt: grep the names from the issue first, using `| head`; read the top file around the matching lines |
| Similarity search is rarely usable and can flood the model's memory | Remove `search_similar_code` from the main agent |
| Files are big; the change is often deep inside | Never read whole files; `grep -n`, then read about 60–100 lines around the match |
| The code graph misses async code, imports and constants | Use the graph only for "who calls this?" |
| A quarter of tasks are features | Separate prompt guidance for "add this" vs "fix this" |
| `hints_text` is always empty | Drop `{hints}` from the prompt |
