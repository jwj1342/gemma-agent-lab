# CELL 0 markdown
# Gemma 4 LB: 58 Tasks, Bronze Is a 124-Team Tie


**The unit.** The Data page says the hidden test set is "about 120 tasks, evenly
divided between the public and private splits", so it is natural to read this board in sixtieths.
It is not sixtieths. The board shows scores truncated to 2 decimals, and the only
public task count between 30 and 130 that produces exactly the 10 scores on it (under
Kaggle's truncation; under rounding, no count reproduces the set exactly) is **58**. One task is worth 0.0172; 0.12 is 7 tasks (seven sixtieths would
show as 0.11); the step above 0.13 is 0.15. Meta Kaggle records the two facts this rests on: the public
board is 50% of the test set, and scores are truncated to 2 decimals.

**The board** (863 teams, day 6 of 70). The bronze cut,
rank 100, is 6 tasks, and **124 teams share that
score** (ranks 88-211). Only the 13
who got there first are inside the band: within a tie, rank is submission time.

**The noise.** One submission's binomial standard deviation at the bronze cut is 2.32
tasks, and 525 teams (60.8% of the board) sit within one of it. The
nonzero scores spread with a standard deviation of 1.72 tasks, which is what a single
agent would show if every team had re-submitted it (1.74, 90% range
1.66-1.81). Teams do differ (the shape rejects "one agent", p =
5.6e-11), but their differences add almost nothing to the spread the draw alone makes.

**What survives to private** (modelled on 58 private tasks). For two submissions near
the cut whose true pass rates differ by one task, the private split keeps their public order
0.473 of the time if their outcomes are unrelated, and 0.486 at the
agreement level of AIMO teams' two final picks (kappa 0.42). Three tasks apart:
0.651 and 0.813. If the board froze today, a public top-10 team would
finish outside the top 100 with probability 0.638 to 0.831.

**What to do with it.** Read scores in tasks and gaps in standard deviations. Use both final
picks, and spend the second on a *different* agent rather than a near-copy of your best: a
near-copy tied with your best adds 0.80 expected private tasks, an unrelated agent two
tasks lower on public adds 1.02. Count the 129 development tasks on which
your two agents disagree; that number moves the answer more than any decimal on the board.

Sections: 1 what the competition says, 2 the board in tasks, 3 how much of it is the draw, 4 two
submissions, 5 the frozen-board simulation, 6 the selection rule and a calculator for your own
scores, 7 what this does not know.

## 0. Setup and knobs

Nothing here runs a model. The notebook reads the stored board snapshot, the competition's own
data, and Meta Kaggle, and it needs no internet and no accelerator. The knobs:

* `BOARD_CSV`: point it at a fresh board download (Leaderboard tab, Download) to redo every
  count on today's board instead of the stored snapshot.
* `MY_PUBLIC_SCORES`: swap in the public scores of your own submissions; section 6 turns them
  into tasks and says which gaps are real.
* `MY_DISCORDANT_DEV_TASKS`: change the `None` to the number of the 129 development tasks on which
  exactly one of your two best agents passed. That is the one number about your agents that this
  notebook cannot see, and it moves the answer more than anything else.

def rec(key, value):

    return value


def find(name, required=True):
    hits = sorted(p for p in INPUT.rglob(name) if p.is_file())
    if not hits and required:
        raise FileNotFoundError(f"{name} not found under {INPUT}")
    return hits[0] if hits else None


def scan(name, cols, key, keep, newlines=False):
    """Stream one Meta Kaggle CSV; keep only `cols`, and rows whose `key` is in `keep`."""
    ro = pacsv.ReadOptions(block_size=64 << 20)
    po = pacsv.ParseOptions(newlines_in_values=newlines)
    co = pacsv.ConvertOptions(include_columns=cols, column_types={c: pa.string() for c in cols})
    vs = pa.array(sorted({str(v) for v in keep}))
    parts = []
    for b in pacsv.open_csv(find(name), read_options=ro, parse_options=po, convert_options=co):
        b = b.filter(pc.is_in(b.column(key), value_set=vs))
        if b.num_rows:
            parts.append(b)
    return pa.Table.from_batches(parts).to_pandas() if parts else pd.DataFrame(columns=cols)

# Which public task counts n reproduce the displayed scores? Exact integer arithmetic. A displayed
# value v (in units of 10^-DEC) comes from k solved tasks if v == floor(k * 10^DEC / n) (Kaggle
# truncates displayed scores) or v == round-half-up(k * 10^DEC / n) (checked as the alternative).
#   consistent: every displayed value is reachable from some k
#   exact:      and every reachable value up to the top displayed score is actually held by a team,
#               i.e. no count k between 0 and the leader is unoccupied on a board this size
S = 10 ** DEC
shown = sorted({int(round(float(s) * S)) for s in board["Score"]})
fits, exact = {}, {}
for mode in ("truncate", "round"):
    fits[mode], exact[mode] = [], []
    for n in range(30, 131):
        vals = [(k * S) // n if mode == "truncate" else (2 * k * S + n) // (2 * n) for k in range(n + 1)]
        if all(v in set(vals) for v in shown):
            fits[mode].append(n)
            if sorted({v for v in vals if v <= max(shown)}) == shown:
                exact[mode].append(n)
    print(f"{mode:<9} consistent task counts between 30 and 130: {len(fits[mode]):>3} values "
          f"({', '.join(map(str, fits[mode][:6]))}{', ...' if len(fits[mode]) > 6 else ''}); "
          f"exact fits: {exact[mode] if exact[mode] else 'none'}")
print(f"the Data page's implied {STATED_PUBLIC}: consistent under truncation? {STATED_PUBLIC in fits['truncate']}; "
      f"under rounding? {STATED_PUBLIC in fits['round']}")

          f"{'match' if TRUNC_DEC == DEC else 'MISMATCH'}")

# CELL 10 markdown
### Where the medal cuts sit, and how many teams are within one standard deviation of them

Kaggle's medal table for 250 to 999 teams: gold to the top 10 plus one per 500 teams, silver to
the top 50, bronze to the top 100 (from 1,000 teams on, bronze becomes the top 10% and silver the
top 5%). One submission's public score is a count out of the public task count, so its binomial
standard deviation in tasks is sqrt(n p (1 - p)) at pass rate p. The table counts the teams whose
displayed task count is within one and two such deviations of each cut.

# CELL 11 code
def medal_ranks(n_teams):
    gold = 10 + n_teams // 500
    if n_teams >= 1000:
        return {"gold": gold, "silver": n_teams * 5 // 100, "bronze": n_teams // 10}
    if n_teams >= 250:
        return {"gold": gold, "silver": 50, "bronze": 100}
    if n_teams >= 100:
        return {"gold": 10, "silver": int(0.2 * n_teams), "bronze": int(0.4 * n_teams)}
    return {"gold": int(0.1 * n_teams), "silver": int(0.2 * n_teams), "bronze": int(0.4 * n_teams)}


print("Kaggle medal table: 250-999 teams -> gold top 10 + 1 per 500 teams, silver top 50, bronze top 100;\n"
      "                    1,000+ teams -> gold top 10 + 1 per 500 teams, silver top 5%, bronze top 10%")
MEDAL = medal_ranks(N_TEAMS)
BRONZE = MEDAL["bronze"]
cuts = {"top 10": 10, **{f"{k} (top {v})": v for k, v in MEDAL.items()}}
rows = []
for name, r in cuts.items():
    k = int(board["tasks"].iloc[r - 1])          # board is sorted by rank; ranks are 1..N
    p = k / N_PUBLIC
    sd = math.sqrt(N_PUBLIC * p * (1 - p))
    d = (board["tasks"] - k).abs()
    rows.append({"cut": name, "rank": r, "score": board["Score"].iloc[r - 1],
                 "tasks": k, "teams_on_that_score": int((board["tasks"] == k).sum()),
                 "sd_tasks": round(sd, 2),
                 "within_1sd": int((d <= sd).sum()), "within_2sd": int((d <= 2 * sd).sum()),
                 "within_1sd_%": round(100 * (d <= sd).mean(), 1),
                 "within_2sd_%": round(100 * (d <= 2 * sd).mean(), 1)})
cut_tab = pd.DataFrame(rows).set_index("cut")
print(f"{N_TEAMS} teams -> medal ranks {MEDAL}")
print(cut_tab.to_string())

## 3. How much of the board is the draw?

Two tests, both on the stored board. They were added after the board was downloaded (the
pre-registered version was the copy test alone), and they say so here.

**Spread.** If every team re-submitted one and the same agent, with each team's actual number of
submissions and the board showing each team's best, how wide would the board be? Fitting that one
agent's pass rate to the nonzero teams and re-rolling the board gives the answer to compare with
the real spread.

**Copies.** If every team's score were its own independent draw around its own pass rate, the
number of teams at a count k could exceed the average of its two neighbours only by a small
factor (the exact bound is printed, allowing for the best of several submissions). A block well
above it is made of teams that share the same outcomes, i.e. run the same agent, and would land
on the same private score together.

PGRID = np.linspace(1e-4, 0.999, 4000)


def spike_bound(n, k, m):
    """Max over p of pmf(k) / mean(pmf(k-1), pmf(k+1)) for the best of m Binomial(n, p) draws."""
    F = lambda x: binom.cdf(x, n, PGRID)
    pm = lambda x: F(x) ** m - F(x - 1) ** m
    den = (pm(k - 1) + pm(k + 1)) / 2
    r = np.where(den > 1e-300, pm(k) / np.maximum(den, 1e-300), 0.0)
    return float(r.max())

## 4. Two submissions, 1 to 3 tasks apart: does the public order survive?

Take two submissions whose true pass rates differ by 1, 2 or 3 tasks, both near the bronze cut.
Their public and private scores come from disjoint task sets. What decides whether the public
order survives is how many tasks the two agents disagree on: if they fail and pass the same tasks,
their difference is nearly noiseless; if their outcomes are unrelated, it is as noisy as it gets.
The exact calculation below enumerates every split outcome (no sampling).

The agreement level cannot be read off the board, so it is calibrated on the closest closed
competitions with the same shape: the AIMO Progress Prize 1 and 2, where each team's final
submissions were rerun on the same 50 private problems, pass or fail each. How far apart one
team's two picks landed, relative to two independent submissions, is the calibration (called
kappa below: 1 = unrelated outcomes, 0 = identical outcomes).

def diff_pmf(n, a, b):
    """Exact pmf of (#tasks only A passes) - (#tasks only B passes) over n tasks."""
    lf = np.array([math.lgamma(i + 1) for i in range(n + 1)])
    la = math.log(a) if a > 0 else -np.inf
    lb = math.log(b) if b > 0 else -np.inf
    lc = math.log(1 - a - b) if a + b < 1 else -np.inf
    out = np.zeros(2 * n + 1)
    for i in range(n + 1):
        for j in range(n + 1 - i):
            k = n - i - j
            t = lf[n] - lf[i] - lf[j] - lf[k] + (i * la if i else 0.0) + (j * lb if j else 0.0) \
                + (k * lc if k else 0.0)
            if np.isfinite(t):
                out[i - j + n] += math.exp(t)
    return out


def pair_rates(p_hi, p_lo, kappa):
    """Per-task rates of 'only the better passes' (a) and 'only the worse passes' (b)."""
    indep = p_hi * (1 - p_lo) + p_lo * (1 - p_hi)
    disc = max(kappa * indep, p_hi - p_lo)            # cannot disagree on fewer tasks than the gap
    return (disc + (p_hi - p_lo)) / 2, (disc - (p_hi - p_lo)) / 2, disc


def order_survival(p_hi, p_lo, kappa, n_pub=None, n_priv=None):
    n_pub, n_priv = n_pub or N_PUBLIC, n_priv or N_PRIVATE
    a, b, disc = pair_rates(p_hi, p_lo, kappa)
    fp, fv = diff_pmf(n_pub, a, b), diff_pmf(n_priv, a, b)
    xp, xv = np.arange(-n_pub, n_pub + 1), np.arange(-n_priv, n_priv + 1)
    up, dn, tie_p = fp[xp > 0].sum(), fp[xp < 0].sum(), fp[xp == 0].sum()
    uv, dv, tie_v = fv[xv > 0].sum(), fv[xv < 0].sum(), fv[xv == 0].sum()
    strict = up + dn
    return {"discordant tasks per split": round(disc * n_priv, 2),
            "public shows the better one ahead": round(up, 3), "public tie": round(tie_p, 3),
            "private keeps the public order": round((up * uv + dn * dv) / strict, 3),
            "private tie": round(tie_v, 3),
            "private reverses it": round((up * dv + dn * uv) / strict, 3)}

# CELL 22 markdown
## 5. If the board froze today, who keeps a medal?

This is a model of the private board, not a measurement of it. Each team's true pass rate is
estimated from its public count with an empirical-Bayes prior fitted to the whole board (a grid
prior, fitted by EM), then a private count is drawn for every team on the private split, and teams
are re-ranked with private ties broken by public rank (which flatters persistence). It runs with
independent outcomes (kappa 1), and with the teams' noise shrunk to the AIMO kappa, as if every
pair of teams were as alike as one team's two picks; the truth for different teams should sit
between the two. When section 3 finds a copy block, a third run treats that whole block as one
agent that lands on one private score. The legacy NumPy generator is used so the draws are
identical on every NumPy version.

# CELL 23 code
def thinned_lik(n, kappa, grid):
    """P(count k | p) when outcomes carry a share kappa of the binomial variance:
    count = round(Binomial(m, p) * n / m) with m = round(n / kappa). kappa = 1 is the binomial."""
    m = max(n, int(round(n / kappa)))
    j = np.arange(m + 1)
    kk = np.floor(j * n / m + 0.5).astype(int)
    pj = binom.pmf(j[:, None], m, grid[None, :])
    L = np.zeros((n + 1, len(grid)))
    np.add.at(L, kk, pj)
    return L, m


def fit_prior(counts, L, iters=3000):
    """Nonparametric maximum-likelihood prior on the grid (EM)."""
    hist = np.bincount(counts, minlength=L.shape[0]).astype(float)
    w = np.full(L.shape[1], 1.0 / L.shape[1])
    for _ in range(iters):
        post = L * w[None, :]
        post /= np.maximum(post.sum(1, keepdims=True), 1e-300)
        w = (hist[:, None] * post).sum(0) / hist.sum()
    return w


def simulate_board(kappa, n_boards=N_BOARDS, seed=SEED, shared_block=None):
    """shared_block = a public task count whose teams are treated as one agent: one private draw
    per simulated board, copied to every team in the block (they stay tied, ordered by time)."""
    grid = np.linspace(0, 0.6, 241)
    Lpub, _ = thinned_lik(N_PUBLIC, kappa, grid)
    w = fit_prior(board["tasks"].values, Lpub)
    post = Lpub[board["tasks"].values] * w[None, :]
    post /= post.sum(1, keepdims=True)
    cdf = np.cumsum(post, 1)
    m = max(N_PRIVATE, int(round(N_PRIVATE / kappa)))
    rs = np.random.RandomState(seed)
    pub_rank = board["Rank"].values
    in_band = np.zeros(N_TEAMS)
    top1 = 0
    cut_tasks = np.zeros(n_boards, dtype=int)
    for s in range(n_boards):
        u = rs.random_sample(N_TEAMS)
        gi = (cdf < u[:, None]).sum(1).clip(0, len(grid) - 1)
        draws = rs.binomial(m, grid[gi])
        priv = np.floor(draws * N_PRIVATE / m + 0.5).astype(int)
        if shared_block is not None:
            blk_idx = np.flatnonzero(board["tasks"].values == shared_block)
            priv[blk_idx] = priv[blk_idx[0]]
        order = np.lexsort((pub_rank, -priv))
        rank = np.empty(N_TEAMS, dtype=int)
        rank[order] = np.arange(1, N_TEAMS + 1)
        in_band += rank <= BRONZE
        top1 += rank[0] == 1
        cut_tasks[s] = priv[order[BRONZE - 1]]
    keep = in_band / n_boards
    return {"kappa": kappa, "keep": keep, "top1": top1 / n_boards, "cut": cut_tasks, "prior": (grid, w)}

## 6. Which two submissions to select, priced in tasks

You get two final selections and the better private score of the two counts. So the question for
the second slot is not "is it better than my first?" but "how much private score does adding it
buy?", which is E[max(A, B)] - E[A]. That gain depends on two things only: how far below your best
it sits on public, in tasks, and how many tasks the two agents disagree on. The table uses a flat
prior on the true gap (the public gap taken at face value), so predictive private gaps have
standard deviation sqrt(2 x discordant tasks). Thresholds are in those standard deviations, so they
hold at any score level.

# CELL 26 code
def second_pick_gain(gap, disc):
    """Expected private tasks gained by adding a pick `gap` tasks below the best on public, when the
    two disagree on `disc` tasks per split: E[max(0, B - A)] with B - A ~ N(-gap, 2 * disc)."""
    s = math.sqrt(2 * disc)
    t = gap / s
    return s * norm.pdf(t) - gap * norm.cdf(-t), s


p_ind = BRONZE_K / N_PUBLIC
disc_ind = 2 * p_ind * (1 - p_ind) * N_PRIVATE
disc_levels = {"near-copy (2 tasks)": 2.0,
               f"AIMO kappa ({KAPPA * disc_ind:.1f} tasks)": KAPPA * disc_ind,
               f"independent ({disc_ind:.1f} tasks)": disc_ind}
rows = []
for gap in range(0, 5):
    row = {"public gap (tasks)": gap}
    for lab, dsc in disc_levels.items():
        g, s = second_pick_gain(gap, dsc)
        row[lab] = f"{g:.2f} ({gap / s:.1f} SD)"
    rows.append(row)
gain_tab = pd.DataFrame(rows)
print(f"expected private tasks added by the second pick (and the public gap in predictive SDs), "
      f"base rate {BRONZE_K}/{N_PUBLIC}:")
print(gain_tab.to_string(index=False))
gain_tab.to_csv(WORK / "gemma4_second_pick_gain.csv", index=False)

# the SD threshold at which a second pick stops paying 0.05 tasks, for each disagreement level
for lab, dsc in disc_levels.items():
    s = math.sqrt(2 * dsc)
    lo, hi = 0.0, 10.0
    for _ in range(60):
        x = (lo + hi) / 2
        lo, hi = (x, hi) if second_pick_gain(x * s, dsc)[0] > 0.05 else (lo, x)
    print(f"{lab:<28} a second pick is worth under 0.05 tasks once it trails by {lo:.2f} SD = {lo * s:.1f} tasks")
    if lab.startswith("AIMO"):
        rec("inert_sd", f"{lo:.2f}")
        rec("inert_tasks", f"{lo * s:.1f}")
        rec("aimo_disc", f"{dsc:.1f}")
        rec("gain0_aimo", f"{second_pick_gain(0, dsc)[0]:.2f}")
        rec("gain1_aimo", f"{second_pick_gain(1, dsc)[0]:.2f}")
    if lab.startswith("near-copy"):
        rec("gain0_copy", f"{second_pick_gain(0, dsc)[0]:.2f}")
    if lab.startswith("independent"):
        rec("gain1_ind", f"{second_pick_gain(1, dsc)[0]:.2f}")
        rec("gain2_ind", f"{second_pick_gain(2, dsc)[0]:.2f}")
rec("disc_ind", f"{disc_ind:.1f}")

## 7. What this notebook does not know

* **Private scores are modelled, never observed.** The binomial arithmetic assumes the hidden
  tasks were split into public and private at random, task by task. If the split followed
  repositories instead, public and private differ by more than this, and every "keeps the order"
  probability above is an upper bound.
* **The private split is assumed to be the same size as the public one** (58 tasks),
  which is what 50% of about 120 implies.
* **The board shows each team's best public submission.** A team that submitted the same agent
  many times shows its luckiest run on the public tasks, and that luck does not carry over to
  private. The simulation treats each board score as one draw, so it understates the fall for
  heavy submitters.
* **Kappa comes from math problems, not repositories.** It anchors the scale of "how alike are
  two picks"; it is not a measurement of Gemma agents. Your own count of disagreeing development
  tasks (`MY_DISCORDANT_DEV_TASKS`) replaces it. If different teams' agents were more alike than one
  AIMO team's two picks, the public order would persist better than section 5 says.
* **Ties:** the board orders tied teams by submission time, and the simulation breaks private
  ties by public rank, which flatters the current order.
* **One snapshot, day 6 of 70.** Point `BOARD_CSV` at a fresh
  download to redo every number.
