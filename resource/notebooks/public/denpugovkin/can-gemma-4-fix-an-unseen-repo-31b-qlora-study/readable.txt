- The competition scores the fraction of repository issues whose agent patch passes hidden tests. It accepts a ZIP of agent configuration and optional LoRA weights, not a CSV.

<h2 style="color:#0B1F3A;border-bottom:3px solid #00B4A6;padding-bottom:6px;">2. What do public repairs actually look like?</h2>

For each reference diff we reconstruct the **before** and **after** side of source hunks. The model sees the issue and before-side context, then learns the source-only unified diff. The notebook excludes `test_patch` entirely. The visual audit shows repository balance, edit complexity, and what the context limit removes. This teaches patch drafting after localization; it does not train tool use or prove end-to-end repair ability.

# CELL 6 code
def is_source_path(path):
    return (path.endswith('.py') and '/test' not in path
            and not path.startswith('test') and not path.endswith('_test.py'))

def source_only_diff(patch):
    """Retain complete Python source file diffs, never test or non-Python files."""
    sections = re.split(r'(?=^diff --git )', patch, flags=re.MULTILINE)
    kept = []
    for section in sections:
        if not section.startswith('diff --git '):
            continue
        plus = next((line[6:] for line in section.splitlines()
                     if line.startswith('+++ b/')), None)
        if plus and is_source_path(plus) and any(
                line.startswith('@@') for line in section.splitlines()):
            kept.append(section.rstrip('\n'))
    return '\n'.join(kept) + ('\n' if kept else '')

def source_edit_pair(patch):
    before, after, path = [], [], None
    for line in patch.splitlines():
        if line.startswith('diff --git '):
            path = None
        elif line.startswith('+++ b/'):
            path = line[6:]
            if is_source_path(path):
                before.append(f'FILE {path}')
                after.append(f'FILE {path}')
            else:
                path = None
        elif path and line.startswith('@@'):
            before.append('HUNK')
            after.append('HUNK')
        elif path and line.startswith(' '):
            before.append(line[1:]); after.append(line[1:])
        elif path and line.startswith('-') and not line.startswith('---'):
            before.append(line[1:])
        elif path and line.startswith('+') and not line.startswith('+++'):
            after.append(line[1:])
    return '\n'.join(before), '\n'.join(after)

def source_stats(patch):
    files, hunks, changed, active = 0, 0, 0, False
    for line in patch.splitlines():
        if line.startswith('diff --git '):
            active = False
        elif line.startswith('+++ b/'):
            active = is_source_path(line[6:])
            files += int(active)
        elif active and line.startswith('@@'):
            hunks += 1
        elif active and line.startswith(('+', '-')) and not line.startswith(('+++', '---')):
            changed += 1
    return files, hunks, changed

examples = []
flow = Counter()
for row in rows:
    flow['all'] += 1
    before, after = source_edit_pair(row.get('patch') or '')
    issue = row.get('problem_statement') or ''
    if not (before and after and before != after and issue):
        continue
    flow['source_edit'] += 1
    if max(len(before), len(after)) > 2600 or len(issue) > 3500:
        continue
    flow['length_bound'] += 1
    files, hunks, changed = source_stats(row.get('patch') or '')
    target = source_only_diff(row.get('patch') or '')
    assert target and 'diff --git ' in target
    examples.append(dict(id=row['instance_id'], repo=row['repo'], issue=issue,
                         before=before, after=after, target=target,
                         changed_lines=changed, source_files=files, hunks=hunks))
assert len(examples) >= 20, 'Too few bounded source edits for this notebook'
print('Usable examples:', len(examples))

<h2 style="color:#0B1F3A;border-bottom:3px solid #00B4A6;padding-bottom:6px;">3. Can two T4 GPUs train a 31B QLoRA adapter?</h2>

The competition serves `gemma-4-31b-it-qat-w4a16-ct` for inference. The exact unquantized QAT training checkpoint occupies **62.6 GB on disk**; this Kaggle T4 ×2 recipe instead uses Unsloth's **19.1 GB prequantized 31B** training checkpoint. That is a different base, so an adapter learned here is only a transfer candidate. LoRA compatibility and issue-level improvement must be checked with the competition server. Unsloth documents model splitting with `device_map="balanced"`; this notebook uses both T4s, short sequences, rank 8, batch 1, and gradient checkpointing. DDP would replicate the 31B model on each 16 GB GPU, so we do not launch it here. An OOM or unsupported model load should fail visibly.

# CELL 29 markdown
### Paired generation on the unseen repository

Up to eight tokenizer-fitting Rich issues are drafted twice after training: once with PEFT disabled (base), once with the trained adapter. Each draft is capped at 256 new tokens; after four paired issues, a 45-minute soft limit stops further validation. Actual IDs and stop reason are saved. `git apply --numstat` checks whether each output parses as a diff; it does **not** apply the patch or run tests. Changed-line F1 checks exact added and removed lines, while path match checks the gold source path. These are intentionally stricter than loss and much cheaper than a 12-hour hidden harness run, but the provided source excerpt is oracle-localized.

Each generation also uses Transformers `max_time=180` seconds; this is checked between decoding iterations, so a slow iteration can overshoot. The trained ZIP has already been saved.

# CELL 30 code
# Paired generation: same model and prompts, adapter disabled/enabled.
# These are oracle-localized patch drafts, not full agent episodes.
def prompt_text(row):
    user = f'Issue:\n{row["issue"]}\n\nCurrent source excerpt:\n{row["before"]}'
    return tokenizer.apply_chat_template(
        [{'role':'system','content':SYSTEM}, {'role':'user','content':user}],
        tokenize=False, add_generation_prompt=True).removeprefix('<bos>')

def draft(row):
    encoded = tokenizer(text=prompt_text(row), return_tensors='pt',
                        add_special_tokens=False)
    prompt_tokens = encoded['input_ids'].shape[1]
    generation_budget = min(256, 1024 - prompt_tokens)
    if generation_budget < 32:
        raise RuntimeError(f'Insufficient generation room for {row["id"]}: {prompt_tokens} tokens')
    device = next(model.parameters()).device
    encoded = {key:value.to(device) for key,value in encoded.items()}
    with torch.inference_mode():
        generated = model.generate(**encoded, max_new_tokens=generation_budget,
                                   do_sample=False, use_cache=True, max_time=180.0)
    decoder = tokenizer if callable(getattr(tokenizer,'decode',None)) else tokenizer.tokenizer
    return decoder.decode(generated[0][prompt_tokens:],
                          skip_special_tokens=True).strip()

def changed_lines(diff):
    return Counter(line for line in diff.splitlines()
                   if line.startswith(('+','-'))
                   and not line.startswith(('+++','---')))

def diff_metrics(prediction, reference):
    # git apply --numstat parses diff syntax without modifying a repo.
    parsed = subprocess.run(['git','apply','--numstat','-'],
                            input=prediction.rstrip('\n') + '\n',
                            text=True, capture_output=True)
    valid = parsed.returncode == 0 and bool(parsed.stdout.strip())
    paths = {line[6:] for line in prediction.splitlines()
             if line.startswith('+++ b/')}
    gold_paths = {line[6:] for line in reference.splitlines()
                  if line.startswith('+++ b/')}
    expected = changed_lines(reference)
    actual = changed_lines(prediction)
    common = sum((expected & actual).values())
    precision = common / sum(actual.values()) if actual else 0.0
    recall = common / sum(expected.values()) if expected else 0.0
    f1 = 2*precision*recall/(precision+recall) if precision+recall else 0.0
    return {'valid_diff':bool(valid), 'path_match':paths == gold_paths,
            'changed_line_f1':round(f1,4), 'changed_line_precision':round(precision,4),
            'changed_line_recall':round(recall,4)}
