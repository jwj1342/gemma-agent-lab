# ------------------------------------------------------------

system_prompt = """You are Gemma 4 SWE-Agent.

Your objective is to solve repository-level software engineering
issues and produce the smallest correct patch.

WORKFLOW:

1. Understand the issue.
2. Inspect the repository.
3. Search for relevant code.
4. Read surrounding implementation.
5. Form a concrete hypothesis.
6. Make the smallest necessary change.
7. Run relevant tests.
8. Analyze failures.
9. Iterate when necessary.
10. Submit the final patch only after validation.

RULES:

- Use repository evidence instead of guessing.
- Prefer minimal patches.
- Do not modify unrelated files.
- Preserve existing APIs unless required.
- Inspect callers before changing interfaces.
- Run tests after modifications.
- Never claim success without validation.

FAILURE RECOVERY:

When a test fails:
1. Read the traceback.
2. Locate the responsible code.
3. Update the hypothesis.
4. Make the smallest correction.
5. Run the test again.

STOP CONDITION:

Submit only when the requested behavior is implemented
and relevant tests pass.
"""

with open(
    f"{ROOT}/prompts/system.md",
    "w",
    encoding="utf-8"
) as f:
    f.write(system_prompt)

name: patch-validation

# Patch Validation

Never submit an unvalidated patch.
"""

def build_training_example(row):

    return {
        "instance_id": row["instance_id"],

        "repo": row["repo"],

        "base_commit": row["base_commit"],

        "problem_statement": row["problem_statement"],

        "agent_trajectory": [

            {
                "step": 1,
                "type": "understand_issue",
                "input": row["problem_statement"]
            },

            {
                "step": 2,
                "type": "inspect_repository",
                "tool": "get_status"
            },

            {
                "step": 3,
                "type": "search_code",
                "tool": "search_similar_code"
            },

            {
                "step": 4,
                "type": "read_code",
                "tool": "read_file"
            },

            {
                "step": 5,
                "type": "reason",
                "instruction":
                    "Identify the smallest code change "
                    "that addresses the issue."
            },

            {
                "step": 6,
                "type": "edit",
                "tool": "edit_file"
            },

            {
                "step": 7,
                "type": "validate",
                "tool": "run_command",
                "tests": row["FAIL_TO_PASS"]
            },

            {
                "step": 8,
                "type": "regression_check",
                "tests": row["PASS_TO_PASS"]
            },

            {
                "step": 9,
                "type": "submit",
                "tool": "submit_patch"
            }
        ],

        # Gold patch is kept separately.
        # It will be used for supervised training later.
        "gold_patch": row["patch"],

        "fail_to_pass": row["FAIL_TO_PASS"],

        "pass_to_pass": row["PASS_TO_PASS"]
    }

# ------------------------------------------------------------
# Convert each SWE instance into an SFT conversation
# ------------------------------------------------------------

def make_sft_record(row):

    issue = row["problem_statement"]

    fail_tests = row.get("fail_to_pass", [])
    pass_tests = row.get("pass_to_pass", [])

    gold_patch = row.get("gold_patch", "")

    messages = [

        {
            "role": "system",

            "content": (
                "You are an autonomous software engineering agent. "
                "Solve repository-level issues using repository evidence. "
                "Inspect code before editing, make minimal changes, "
                "run relevant tests, and only submit a validated patch."
            )
        },

        {
            "role": "user",

            "content": (
                "Repository:\n"
                f"{row['repo']}\n\n"

                "Base commit:\n"
                f"{row['base_commit']}\n\n"

                "Issue:\n"
                f"{issue}"
            )
        },

        {
            "role": "assistant",

            "content": (
                "I will first inspect the repository state and "
                "identify the files relevant to the issue."
            )
        },

        {
            "role": "tool",

            "name": "get_status",

            "content": (
                "Inspect repository status and structure."
            )
        },

        {
            "role": "assistant",

            "content": (
                "Next I will search the repository for the "
                "implementation related to the reported behavior."
            )
        },

        {
            "role": "tool",

            "name": "search_similar_code",

            "content": (
                "Search for relevant functions, classes, "
                "and related implementations."
            )
        },

        {
            "role": "assistant",

            "content": (
                "I will read the relevant implementation and "
                "its surrounding code before making a change."
            )
        },

        {
            "role": "tool",

            "name": "read_file",

            "content": (
                "Read the relevant source files and nearby code."
            )
        },

        {
            "role": "assistant",

            "content": (
                "Based on the issue and repository evidence, "
                "I will make the smallest change necessary "
                "to address the reported behavior."
            )
        },

        {
            "role": "tool",

            "name": "edit_file",

            "content": (
                "Apply the minimal source-code modification."
            )
        },

        {
            "role": "assistant",

            "content": (
                "The patch is now implemented. "
                "I will run the tests associated with the issue."
            )
        },

        {
            "role": "tool",

            "name": "run_command",

            "content": json.dumps({
                "fail_to_pass": fail_tests,
                "pass_to_pass": pass_tests
            })
        },

        {
            "role": "assistant",

            "content": (
                "The relevant tests should pass after the "
                "correction. I will verify the regression "
                "tests before submitting."
            )
        },

        {
            "role": "tool",

            "name": "run_command",

            "content": json.dumps({
                "regression_tests": pass_tests
            })
        },

        {
            "role": "assistant",

            "content": (
                "The patch has been validated. "
                "I will submit the minimal repository patch."
            )
        },

        {
            "role": "tool",

            "name": "submit_patch",

            "content": "Submit the validated patch."
        }
    ]


    return {
        "instance_id": row["instance_id"],

        "repo": row["repo"],

        "base_commit": row["base_commit"],

        "messages": messages,

        # Gold solution kept as supervision metadata.
        "gold_patch": gold_patch,

        "validation": {
            "fail_to_pass": fail_tests,
            "pass_to_pass": pass_tests
        }
    }


# ------------------------------------------------------------
# Read source dataset
# ------------------------------------------------------------

records = []

with open(
    SOURCE,
    "r",
    encoding="utf-8"
) as f:

    for line in f:

        if line.strip():

            row = json.loads(line)

            records.append(
                make_sft_record(row)
            )


# ------------------------------------------------------------
# Save SFT dataset
# ------------------------------------------------------------

with open(
    OUTPUT,
    "w",
    encoding="utf-8"
) as f:

    for record in records:

        f.write(
            json.dumps(
                record,
                ensure_ascii=False
            ) + "\n"
        )


# ------------------------------------------------------------
# Validation
# ------------------------------------------------------------

assert len(records) > 0

for record in records:

    assert "instance_id" in record
    assert "messages" in record
    assert len(record["messages"]) >= 10
    assert record["gold_patch"] is not None


print("=" * 60)
print("✅ SFT DATASET CREATED")
print("=" * 60)

print("Records:", len(records))

print(
    "Output:",
    OUTPUT
)

print(
    "Size:",
    round(
        OUTPUT.stat().st_size / 1024 / 1024,
        2
    ),
    "MB"
)

# Show first conversation

print("\nFIRST TRAINING RECORD")
print("-" * 60)

for message in first["messages"][:8]:

        )

    print(

import json
from pathlib import Path

ROOT = Path("/kaggle/working/gemma4_swe_agent")
DATA_DIR = ROOT / "data"

FILES = [
    DATA_DIR / "swe_bench_lite_trajectories.jsonl",
    DATA_DIR / "swe_bench_sft.jsonl",
]

print("=" * 70)
print("DATASET DIAGNOSTICS")
print("=" * 70)

for path in FILES:

    print(f"\nFILE: {path}")
    print("-" * 70)

    if not path.exists():
        print("❌ FILE DOES NOT EXIST")
        continue

    size = path.stat().st_size

    print(f"Size: {size:,} bytes")

    with path.open("r", encoding="utf-8") as f:
        lines = f.readlines()

    print(f"Lines: {len(lines)}")

    valid_json = 0
    invalid_json = 0

# 2. SAFE PATH RESOLUTION
# ============================================================

def safe_path(repo_root, relative_path):

    repo_root = Path(repo_root).resolve()

    candidate = (
        repo_root / relative_path
    ).resolve()

    if not str(candidate).startswith(
        str(repo_root)
    ):
        raise ValueError(
            f"Unsafe path: {relative_path}"
        )

    return candidate

class TrajectoryRecorder:

    def __init__(
        self,
        instance_id,
        repo,
        base_commit,
        issue
    ):

        self.instance_id = instance_id
        self.repo = repo
        self.base_commit = base_commit
        self.issue = issue

        self.started_at = (
            datetime.utcnow().isoformat()
            + "Z"
        )

        self.steps = []

        self.step_id = 0

    def record(
        self,
        event_type,
        tool=None,
        arguments=None,
        result=None,
        success=None,
        duration=None
    ):

        self.step_id += 1

        event = {

            "step": self.step_id,

            "timestamp":
                datetime.utcnow().isoformat()
                + "Z",

            "type": event_type,

            "tool": tool,

            "arguments": arguments,

            "result": result,

            "success": success,

            "duration_seconds": duration,
        }

        self.steps.append(event)

        return event

    def save(self, path):

        trajectory = {

            "instance_id":
                self.instance_id,

            "repo":
                self.repo,

            "base_commit":
                self.base_commit,

            "problem_statement":
                self.issue,

            "started_at":
                self.started_at,

            "steps":
                self.steps,
        }

        path = Path(path)

        with path.open(
            "w",
            encoding="utf-8"
        ) as f:

            json.dump(
                trajectory,
                f,
                indent=2,
                ensure_ascii=False
            )

        return path

# 4. SWE REPOSITORY ENVIRONMENT
# ============================================================

class SWEEnvironment:

    def __init__(
        self,
        repo_root,
        recorder
    ):

        self.repo_root = Path(
            repo_root
        ).resolve()

        self.recorder = recorder

        if not self.repo_root.exists():

            raise FileNotFoundError(
                f"Repository not found: "
                f"{self.repo_root}"
            )


    # --------------------------------------------------------
    # GET STATUS
    # --------------------------------------------------------

    def get_status(self):

        start = time.time()

        try:

            result = subprocess.run(
                [
                    "git",
                    "status",
                    "--short"
                ],
                cwd=self.repo_root,
                capture_output=True,
                text=True,
                timeout=30
            )

            status = result.stdout

            if not status:
                status = "clean"

            output = {
                "status": status,
                "return_code":
                    result.returncode
            }

            self.recorder.record(
                "tool_call",
                "get_status",
                {},
                output,
                result.returncode == 0,
                time.time() - start
            )

            return output

        except Exception as e:

            error = {
                "error": str(e)
            }

            self.recorder.record(
                "tool_call",
                "get_status",
                {},
                error,
                False,
                time.time() - start
            )

            return error


    # --------------------------------------------------------
    # READ FILE
    # --------------------------------------------------------

    def read_file(
        self,
        path,
        start_line=None,
        end_line=None
    ):

        start = time.time()

        try:

            file_path = safe_path(
                self.repo_root,
                path
            )

            if not file_path.exists():

                raise FileNotFoundError(
                    path
                )

            text = file_path.read_text(
                encoding="utf-8",
                errors="replace"
            )

            lines = text.splitlines()

            if start_line is not None:

                start_index = max(
                    0,
                    start_line - 1
                )

            else:

                start_index = 0

            if end_line is not None:

                end_index = end_line

            else:

                end_index = len(lines)

            selected = lines[
                start_index:end_index
            ]

            output = {
                "path": path,
                "start_line":
                    start_index + 1,
                "end_line":
                    start_index
                    + len(selected),
                "content":
                    "\n".join(selected)
            }

            self.recorder.record(
                "tool_call",
                "read_file",
                {
                    "path": path,
                    "start_line": start_line,
                    "end_line": end_line
                },
                output,
                True,
                time.time() - start
            )

            return output

        except Exception as e:

            output = {
                "error": str(e)
            }

            self.recorder.record(
                "tool_call",
                "read_file",
                {
                    "path": path,
                    "start_line": start_line,
                    "end_line": end_line
                },
                output,
                False,
                time.time() - start
            )

            return output


    # --------------------------------------------------------
    # SEARCH CODE
    # --------------------------------------------------------

    def search_code(
        self,
        pattern,
        path=None
    ):

        start = time.time()

        try:

            target = (
                safe_path(
                    self.repo_root,
                    path
                )
                if path
                else self.repo_root
            )

            command = [
                "grep",
                "-R",
                "-n",
                "-I",
                pattern,
                str(target)
            ]

            result = subprocess.run(
                command,
                cwd=self.repo_root,
                capture_output=True,
                text=True,
                timeout=60
            )

            lines = result.stdout.splitlines()

            # Limit observation size
            lines = lines[:100]

            output = {
                "matches": lines,
                "count": len(lines),
                "return_code":
                    result.returncode
            }

            self.recorder.record(
                "tool_call",
                "search_code",
                {
                    "pattern": pattern,
                    "path": path
                },
                output,
                True,
                time.time() - start
            )

            return output

        except Exception as e:

            output = {
                "error": str(e)
            }

            self.recorder.record(
                "tool_call",
                "search_code",
                {
                    "pattern": pattern,
                    "path": path
                },
                output,
                False,
                time.time() - start
            )

            return output


    # --------------------------------------------------------
    # CODE NEIGHBORS
    # --------------------------------------------------------

    def get_code_neighbors(
        self,
        path,
        line,
        radius=20
    ):

        start = time.time()

        try:

            file_path = safe_path(
                self.repo_root,
                path
            )

            lines = file_path.read_text(
                encoding="utf-8",
                errors="replace"
            ).splitlines()

            center = max(
                1,
                int(line)
            )

            start_line = max(
                1,
                center - radius
            )

            end_line = min(
                len(lines),
                center + radius
            )

            content = "\n".join(
                f"{i}: {lines[i-1]}"
                for i in range(
                    start_line,
                    end_line + 1
                )
            )

            output = {
                "path": path,
                "start_line": start_line,
                "end_line": end_line,
                "content": content
            }

            self.recorder.record(
                "tool_call",
                "get_code_neighbors",
                {
                    "path": path,
                    "line": line
                },
                output,
                True,
                time.time() - start
            )

            return output

        except Exception as e:

            output = {
                "error": str(e)
            }

            self.recorder.record(
                "tool_call",
                "get_code_neighbors",
                {
                    "path": path,
                    "line": line
                },
                output,
                False,
                time.time() - start
            )

            return output


    # --------------------------------------------------------
    # EDIT FILE
    # --------------------------------------------------------

    def edit_file(
        self,
        path,
        old_text,
        new_text
    ):

        start = time.time()

        try:

            file_path = safe_path(
                self.repo_root,
                path
            )

            original = file_path.read_text(
                encoding="utf-8",
                errors="replace"
            )

            occurrences = original.count(
                old_text
            )

            if occurrences != 1:

                raise ValueError(
                    "old_text must occur "
                    f"exactly once; "
                    f"found {occurrences}"
                )

            updated = original.replace(
                old_text,
                new_text,
                1
            )

            file_path.write_text(
                updated,
                encoding="utf-8"
            )

            output = {
                "path": path,
                "changed": True,
                "occurrences": 1
            }

            self.recorder.record(
                "tool_call",
                "edit_file",
                {
                    "path": path,
                    "old_text": old_text,
                    "new_text": new_text
                },
                output,
                True,
                time.time() - start
            )

            return output

        except Exception as e:

            output = {
                "error": str(e),
                "changed": False
            }

            self.recorder.record(
                "tool_call",
                "edit_file",
                {
                    "path": path
                },
                output,
                False,
                time.time() - start
            )

            return output

# JSON SAFETY

def json_safe(value):
    if value is None:
        return None

    if isinstance(value, Path):
        return str(value)

    if isinstance(value, dict):
        return {
            str(k): json_safe(v)
            for k, v in value.items()
        }

    if isinstance(value, (list, tuple)):
        return [json_safe(v) for v in value]

    if isinstance(value, (str, int, float, bool)):
        return value

    return str(value)

class RealTrajectoryRecorder:

    def __init__(
        self,
        trace_file,
        repo,
        base_commit,
        issue,
    ):
        self.trace_file = Path(trace_file)
        self.repo = repo
        self.base_commit = base_commit
        self.issue = issue
        self.steps = []

    def record(
        self,
        tool,
        arguments,
        result,
        success,
        duration,
    ):

        self.steps.append({
            "step": len(self.steps) + 1,
            "timestamp": datetime.now(
                timezone.utc
            ).isoformat(),

            "type": "tool_call",

            "tool": str(tool),

            "arguments": json_safe(arguments),

            "result": json_safe(result),

            "success": bool(success),

            "duration_seconds": float(duration),
        })

    def save(self):

        trajectory = {
            "trajectory_version": "1.0",

            "instance_id": INSTANCE_ID,

            "created_at": datetime.now(
                timezone.utc
            ).isoformat(),

            "repo": self.repo,

            "base_commit": self.base_commit,

            "issue": self.issue,

            "steps": self.steps,
        }

        self.trace_file.write_text(
            json.dumps(
                trajectory,
                indent=2,
                ensure_ascii=False,
            ),
            encoding="utf-8",
        )

        return self.trace_file

class RealSWEEnvironment:

    def __init__(
        self,
        repo_root,
        recorder,
    ):

        self.repo_root = Path(repo_root).resolve()

        self.recorder = recorder

    # --------------------------------------------------------
    # SAFE PATH
    # --------------------------------------------------------

    def safe_path(self, relative_path):

        candidate = (
            self.repo_root / relative_path
        ).resolve()

        try:
            candidate.relative_to(
                self.repo_root
            )
        except ValueError:
            raise ValueError(
                f"Unsafe path: {relative_path}"
            )

        return candidate

    # --------------------------------------------------------
    # TOOL WRAPPER
    # --------------------------------------------------------

    def _call(
        self,
        tool,
        arguments,
        function,
    ):

        start = time.time()

        try:

            result = function()

            success = True

        except Exception as e:

            result = {
                "error": str(e)
            }

            success = False

        duration = time.time() - start

        self.recorder.record(
            tool=tool,
            arguments=arguments,
            result=result,
            success=success,
            duration=duration,
        )

        return result

    # --------------------------------------------------------
    # GET STATUS
    # --------------------------------------------------------

    def get_status(self):

        def operation():

            p = subprocess.run(
                [
                    "git",
                    "status",
                    "--porcelain",
                ],
                cwd=self.repo_root,
                capture_output=True,
                text=True,
            )

            return {
                "status": (
                    "clean"
                    if not p.stdout.strip()
                    else "modified"
                ),

                "return_code": p.returncode,

                "output": p.stdout,
            }

        return self._call(
            "get_status",
            {},
            operation,
        )

    # --------------------------------------------------------
    # SEARCH CODE
    # --------------------------------------------------------

    def search_code(
        self,
        query,
        path=".",
    ):

        arguments = {
            "query": query,
            "path": path,
        }

        def operation():

            search_root = self.safe_path(path)

            matches = []

            for file in search_root.rglob("*"):

                if not file.is_file():
                    continue

                if any(
                    part in {
                        ".git",
                        "__pycache__",
                        ".pytest_cache",
                        "node_modules",
                    }
                    for part in file.parts
                ):
                    continue

                try:

                    text = file.read_text(
                        encoding="utf-8",
                        errors="replace",
                    )

                except Exception:
                    continue

                for line_number, line in enumerate(
                    text.splitlines(),
                    1,
                ):

                    if query.lower() in line.lower():

                        matches.append({
                            "file": str(
                                file.relative_to(
                                    self.repo_root
                                )
                            ),
                            "line": line_number,
                            "text": line,
                        })

                        if len(matches) >= 100:
                            return {
                                "matches": matches
                            }

            return {
                "matches": matches
            }

        return self._call(
            "search_code",
            arguments,
            operation,
        )

    # --------------------------------------------------------
    # READ FILE
    # --------------------------------------------------------

    def read_file(
        self,
        path,
        start_line=1,
        end_line=200,
    ):

        arguments = {
            "path": path,
            "start_line": start_line,
            "end_line": end_line,
        }

        def operation():

            file_path = self.safe_path(path)

            lines = file_path.read_text(
                encoding="utf-8",
                errors="replace",
            ).splitlines()

            start = max(
                1,
                int(start_line),
            )

            end = min(
                len(lines),
                int(end_line),
            )

            content = "\n".join(
                lines[start - 1:end]
            )

            return {
                "path": path,
                "start_line": start,
                "end_line": end,
                "content": content,
            }

        return self._call(
            "read_file",
            arguments,
            operation,
        )

    # --------------------------------------------------------
    # CODE NEIGHBORS
    # --------------------------------------------------------

    def get_code_neighbors(
        self,
        node,
        edge_type=None,
        max_neighbors=50,
    ):

        arguments = {
            "node": node,
            "edge_type": edge_type,
            "max_neighbors": max_neighbors,
        }

        def operation():

            # ------------------------------------------------
            # LOCAL FALLBACK GRAPH
            # ------------------------------------------------
            #
            # For this first environment we locate references
            # to the requested symbol in the repository.
            #
            # This is deliberately recorded as a separate
            # tool call.
            #
            # Later we will replace this with the actual
            # AST/code dependency graph.
            # ------------------------------------------------

            query = node.split("::")[-1]

            matches = []

            for file in self.repo_root.rglob("*.py"):

                if any(
                    part in {
                        ".git",
                        "__pycache__",
                        ".pytest_cache",
                    }
                    for part in file.parts
                ):
                    continue

                try:
                    text = file.read_text(
                        encoding="utf-8",
                        errors="replace",
                    )

                except Exception:
                    continue

                for line_number, line in enumerate(
                    text.splitlines(),
                    1,
                ):

                    if query in line:

                        matches.append({
                            "file": str(
                                file.relative_to(
                                    self.repo_root
                                )
                            ),
                            "line": line_number,
                            "text": line.strip(),
                        })

                        if len(matches) >= max_neighbors:
                            break

                if len(matches) >= max_neighbors:
                    break

            return {
                "node": node,
                "edge_type": edge_type,
                "neighbors": matches,
                "count": len(matches),
            }

        return self._call(
            "get_code_neighbors",
            arguments,
            operation,
        )

    # --------------------------------------------------------
    # RUN COMMAND
    # --------------------------------------------------------

    def run_command(
        self,
        command,
    ):

        arguments = {
            "command": command
        }

        def operation():

            p = subprocess.run(
                command,
                shell=True,
                cwd=self.repo_root,
                capture_output=True,
                text=True,
                timeout=120,
            )

            return {
                "command": command,

                "stdout": p.stdout,

                "stderr": p.stderr,

                "return_code": p.returncode,

                "passed": p.returncode == 0,
            }

        return self._call(
            "run_command",
            arguments,
            operation,
        )

            ).splitlines()

            start = 1 if start_line is None else max(
                1,
                int(start_line),
            )

            end = (
                len(lines)
                if end_line is None
                else min(
                    len(lines),
                    int(end_line),
                )
            )

            return {
                "filepath": filepath,
                "start_line": start,
                "end_line": end,
                "content": "\n".join(
                    f"{i}: {lines[i-1]}"
                    for i in range(start, end + 1)
                ),
            }

        return self._call(
            "read_file",
            arguments,
            fn,
        )

    # ========================================================
    # 3. EDIT FILE
    # ========================================================

    def edit_file(
        self,
        filepath,
        old_string,
        new_string,
        allow_multiple=False,
    ):

        arguments = {
            "filepath": filepath,
            "old_string": old_string,
            "new_string": new_string,
            "allow_multiple": allow_multiple,
        }

        def fn():

            path = self.safe_path(filepath)

            if not path.exists():
                raise FileNotFoundError(filepath)

            content = path.read_text(
                encoding="utf-8"
            )

            count = content.count(old_string)

            if count == 0:
                raise ValueError(
                    "old_string was not found"
                )

            if count > 1 and not allow_multiple:
                raise ValueError(
                    f"old_string occurs {count} times; "
                    "set allow_multiple=True"
                )

            if allow_multiple:
                updated = content.replace(
                    old_string,
                    new_string,
                )
            else:
                updated = content.replace(
                    old_string,
                    new_string,
                    1,
                )

            path.write_text(
                updated,
                encoding="utf-8",
            )

            return {
                "filepath": filepath,
                "replacements": (
                    count if allow_multiple else 1
                ),
                "changed": True,
            }

        return self._call(
            "edit_file",
            arguments,
            fn,
        )

    # ========================================================
    # 4. WRITE FILE
    # ========================================================

    def write_file(
        self,
        filepath,
        content,
    ):

        arguments = {
            "filepath": filepath,
            "content": content,
        }

        def fn():

            path = self.safe_path(filepath)

            path.parent.mkdir(
                parents=True,
                exist_ok=True,
            )

            path.write_text(
                content,
                encoding="utf-8",
            )

            return {
                "filepath": filepath,
                "bytes": len(
                    content.encode("utf-8")
                ),
                "written": True,
            }

        return self._call(
            "write_file",
            arguments,
            fn,
        )

    # ========================================================
    # 5. RUN COMMAND
    # ========================================================

    def run_command(self, command):

        arguments = {
            "command": command
        }

        def fn():

            p = subprocess.run(
                command,
                shell=True,
                cwd=self.repo_root,
                capture_output=True,
                text=True,
                timeout=120,
            )

            return {
                "command": command,
                "stdout": p.stdout,
                "stderr": p.stderr,
                "return_code": p.returncode,
                "passed": p.returncode == 0,
            }

        return self._call(
            "run_command",
            arguments,
            fn,
        )

    # ========================================================
    # 6. SUBMIT PATCH
    # ========================================================

    def submit_patch(self):

        def fn():

            # Make untracked files visible to git diff
            subprocess.run(
                ["git", "add", "-N", "."],
                cwd=self.repo_root,
                capture_output=True,
                text=True,
            )

            p = subprocess.run(
                ["git", "diff", "HEAD"],
                cwd=self.repo_root,
                capture_output=True,
                text=True,
            )

            return {
                "patch": p.stdout,
                "return_code": p.returncode,
                "has_changes": bool(
                    p.stdout.strip()
                ),
            }

        return self._call(
            "submit_patch",
            {},
            fn,
        )

    # ========================================================
    # 7. CODE NEIGHBORS
    # ========================================================

    def get_code_neighbors(
        self,
        node,
        edge_type=None,
        max_neighbors=50,
    ):

        arguments = {
            "node": node,
            "edge_type": edge_type,
            "max_neighbors": max_neighbors,
        }

        def fn():

            symbol = node.split("::")[-1]

            results = []

            for path in self.repo_root.rglob("*.py"):

                if any(
                    x in path.parts
                    for x in [
                        ".git",
                        "__pycache__",
                        ".pytest_cache",
                    ]
                ):
                    continue

                try:
                    text = path.read_text(
                        encoding="utf-8",
                        errors="replace",
                    )
                except Exception:
                    continue

                for line_no, line in enumerate(
                    text.splitlines(),
                    1,
                ):

                    if symbol in line:

                        results.append({
                            "node": symbol,
                            "file": str(
                                path.relative_to(
                                    self.repo_root
                                )
                            ),
                            "line": line_no,
                            "text": line.strip(),
                        })

                        if len(results) >= max_neighbors:
                            return {
                                "node": node,
                                "edge_type": edge_type,
                                "neighbors": results,
                            }

            return {
                "node": node,
                "edge_type": edge_type,
                "neighbors": results,
            }

        return self._call(
            "get_code_neighbors",
            arguments,
            fn,
        )

    # ========================================================
    # 8. SEARCH SIMILAR CODE
    # ========================================================

    def search_similar_code(
        self,
        query,
        k=10,
    ):

        arguments = {
            "query": query,
            "k": k,
        }

        def fn():

            query_terms = set(
                re.findall(
                    r"[A-Za-z_][A-Za-z0-9_]+",
                    query.lower(),
                )
            )

            candidates = []

            for path in self.repo_root.rglob("*.py"):

                if any(
                    x in path.parts
                    for x in [
                        ".git",
                        "__pycache__",
                        ".pytest_cache",
                    ]
                ):
                    continue

                try:
                    text = path.read_text(
                        encoding="utf-8",
                        errors="replace",
                    )
                except Exception:
                    continue

                terms = set(
                    re.findall(
                        r"[A-Za-z_][A-Za-z0-9_]+",
                        text.lower(),
                    )
                )

                overlap = len(
                    query_terms & terms
                )

                if overlap > 0:

                    score = overlap / max(
                        1,
                        len(query_terms),
                    )

                    candidates.append({
                        "file": str(
                            path.relative_to(
                                self.repo_root
                            )
                        ),
                        "score": score,
                    })

            candidates.sort(
                key=lambda x: x["score"],
                reverse=True,
            )

            return candidates[:k]

        return self._call(
            "search_similar_code",
            arguments,
            fn,
        )

    # ========================================================
    # 9. CODE SUBGRAPH
    # ========================================================

    def get_code_subgraph(self, nodes):

        arguments = {
            "nodes": nodes
        }

        def fn():

            graph_nodes = []

            for node in nodes:

                symbol = node.split("::")[-1]

                neighbors = self.get_code_neighbors(
                    symbol,
                    max_neighbors=10,
                )

                graph_nodes.append({
                    "node": node,
                    "neighbors": neighbors,
                })

            return {
                "nodes": graph_nodes
            }

        return self._call(
            "get_code_subgraph",
            arguments,
            fn,
        )

@dataclass
class AgentState:

    issue: str

class ToolRegistry:

    def __init__(self, environment):

        self.environment = environment

        self.tools = {
            "get_status":
                environment.get_status,

            "read_file":
                environment.read_file,

            "edit_file":
                environment.edit_file,

            "write_file":
                environment.write_file,

            "run_command":
                environment.run_command,

            "submit_patch":
                environment.submit_patch,

            "get_code_neighbors":
                environment.get_code_neighbors,

            "search_similar_code":
                environment.search_similar_code,

            "get_code_subgraph":
                environment.get_code_subgraph,
        }


    def execute(
        self,
        tool_name: str,
        arguments: Dict[str, Any],
    ):

        if tool_name not in self.tools:

            return {
                "error":
                    f"Unknown tool: {tool_name}"
            }

        try:

            result = self.tools[
                tool_name
            ](**arguments)

            return result

        except Exception as e:

            return {
                "error": str(e)
            }


# ============================================================
# TOOL CALL PARSER
# ============================================================

class ToolCallParser:

    """
    Expected model output:

    <tool_call>
    {
        "tool": "search_similar_code",
        "arguments": {
            "query": "separability matrix",
            "k": 5
        }
    }
    </tool_call>
    """

    TOOL_PATTERN = re.compile(
        r"<tool_call>\s*(.*?)\s*</tool_call>",
        re.DOTALL,
    )


    @classmethod
    def parse(cls, text):

        match = cls.TOOL_PATTERN.search(
            text
        )

        if not match:

            return None

        payload = match.group(1)

        try:

            data = json.loads(payload)

        except json.JSONDecodeError:

            return {
                "error":
                    "Invalid JSON tool call",
                "raw": payload,
            }

        return {
            "tool":
                data.get("tool"),

            "arguments":
                data.get("arguments", {}),
        }

# ============================================================
# SWE AGENT
# ============================================================

class SWEAgent:

    def __init__(
        self,
        model: ModelPolicy,
        environment,
        max_steps=30,
    ):

        self.model = model

        self.environment = environment

        self.registry = ToolRegistry(
            environment
        )

        self.max_steps = max_steps


    # --------------------------------------------------------
    # SYSTEM PROMPT
    # --------------------------------------------------------

    def system_prompt(self):

        return """
You are an autonomous software engineering agent.

Your task is to solve repository-level software issues.

You have access to tools for:

- repository inspection
- code search
- code graph navigation
- reading files
- editing files
- writing files
- running commands and tests
- submitting patches

WORKFLOW:

1. Understand the issue.
2. Inspect repository state.
3. Locate relevant code.
4. Read the relevant implementation.
5. Inspect related symbols when useful.
6. Form a concrete hypothesis.
7. Modify the minimum necessary code.
8. Run targeted tests.
9. Analyze failures.
10. Repair if necessary.
11. Submit the final patch.

Never invent repository contents.
Use tools to inspect the repository.

When using a tool, output:

<tool_call>
{
  "tool": "TOOL_NAME",
  "arguments": {}
}
</tool_call>

Continue reasoning from the returned observation.
"""


    # --------------------------------------------------------
    # INITIALIZE
    # --------------------------------------------------------

    def initialize(self, issue):

        state = AgentState(
            issue=issue,
            max_steps=self.max_steps,
        )

        state.messages.append({
            "role": "system",
            "content":
                self.system_prompt(),
        })

        state.messages.append({
            "role": "user",
            "content": issue,
        })

        return state


    # --------------------------------------------------------
    # EXECUTE TOOL
    # --------------------------------------------------------

    def execute_tool(
        self,
        state,
        tool_call,
    ):

        tool_name = tool_call["tool"]

        arguments = tool_call.get(
            "arguments",
            {},
        )

        observation = self.registry.execute(
            tool_name,
            arguments,
        )

        state.messages.append({
            "role": "assistant",
            "content":
                json.dumps(
                    tool_call,
                    ensure_ascii=False,
                ),
        })

        state.messages.append({
            "role": "tool",
            "name": tool_name,
            "content":
                json.dumps(
                    observation,
                    ensure_ascii=False,
                    default=str,
                ),
        })

        state.last_observation = observation

        state.steps += 1

        return observation


    # --------------------------------------------------------
    # RUN
    # --------------------------------------------------------

    def run(self, issue):

        state = self.initialize(
            issue
        )

        while (
            state.status == "running"
            and state.steps < state.max_steps
        ):

            # Ask the model what to do next
            response = self.model.generate(
                state.messages
            )

            # ------------------------------------------------
            # FINAL RESPONSE
            # ------------------------------------------------

            if "<tool_call>" not in response:

                state.messages.append({
                    "role": "assistant",
                    "content": response,
                })

                state.status = "finished"

                break


            # ------------------------------------------------
            # PARSE TOOL CALL
            # ------------------------------------------------

            tool_call = ToolCallParser.parse(
                response
            )

            if not tool_call:

                state.messages.append({
                    "role": "tool",
                    "name": "parser",
                    "content":
                        "Invalid tool call format.",
                })

                state.steps += 1

                continue


            if "error" in tool_call:

                state.messages.append({
                    "role": "tool",
                    "name": "parser",
                    "content":
                        json.dumps(
                            tool_call
                        ),
                })

                state.steps += 1

                continue


            # ------------------------------------------------
            # EXECUTE TOOL
            # ------------------------------------------------

            self.execute_tool(
                state,
                tool_call,
            )


            # ------------------------------------------------
            # STOP AFTER SUBMIT PATCH
            # ------------------------------------------------

            if (
                tool_call["tool"]
                == "submit_patch"
            ):

                state.patch = (
                    state.last_observation
                )

                state.status = "finished"

                break


        if state.steps >= state.max_steps:

            state.status = "max_steps"


        return state

  Structured repository navigation using code search, dependency
  neighbors, and code subgraphs to localize software bugs efficiently.
---

# Repository Navigation Skill

Use this skill when the bug is difficult to localize or when several
functions/classes interact.

The goal is NOT to explore the entire repository.

The goal is to identify the smallest relevant execution path.

---

## 1. Start with the issue

Extract:

- error message
- affected behavior
- named class/function/module
- expected behavior
- actual behavior

Create a short internal hypothesis.

---

## 2. Locate symbols

If the issue names a symbol, inspect it directly.

If the symbol is unknown, use:

search_similar_code("<symbol or code concept>", k=10)

Good queries:

- class/function names
- API names
- distinctive implementation concepts

Avoid vague natural-language questions.

---

## 3. Expand locally

Once a relevant symbol is found:

get_code_neighbors(
    "<symbol>",
    max_neighbors=20
)

Use neighbors to identify:

- callers
- callees
- inheritance
- dependencies
- related implementation

Do not expand recursively without a reason.

---

## 4. Build a focused subgraph

When multiple relevant symbols have been identified:

get_code_subgraph([
    "SymbolA",
    "SymbolB",
    "SymbolC"
])

Use the subgraph to understand how the components interact.

The subgraph should remain small and problem-specific.

---

## 5. Combine graph evidence with source code

Graph information is localization evidence.

It is NOT sufficient to make a code change.

Always inspect the actual implementation using:

read_file()

before editing.

---

## 6. Navigation strategy

Use this progression:

Issue
  ↓
Symbol localization
  ↓
Source inspection
  ↓
Code neighbors
  ↓
Focused subgraph
  ↓
Root-cause hypothesis
  ↓
Minimal patch
  ↓
Targeted validation
  ↓
submit_patch()

Do not continue graph exploration after the relevant execution path
is sufficiently understood.

---

## 7. Avoid graph overuse

Do NOT:

- inspect the entire graph
- request huge neighbor lists
- build large unrelated subgraphs
- use embeddings for every trivial bug

For simple issues, ordinary source inspection is enough.

---

## 8. Final localization contract

Before editing, the main agent should be able to answer:

1. Which file contains the bug?
2. Which symbol contains the bug?
3. Who calls that symbol?
4. What input/state causes the failure?
5. Why does the current code produce the wrong behavior?
6. What is the smallest safe change?

If these questions cannot be answered, continue targeted investigation.

If they can, stop exploring and implement the fix.
