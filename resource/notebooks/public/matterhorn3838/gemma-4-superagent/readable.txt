# 📏 0. Leaderboard evidence: read it before you change anything

Everything below is **self-reported by the three source notebooks** (public scores on the competition leaderboard at the time they were written). It is the only ground truth available for design decisions, because the hidden test set cannot be run locally.

| Bundle / version | What it is | Public score |
|:--|:--|:-:|
| 🤖 romanrozen's bundle | Short generic prompt, coder + read-only analyzer, no `eval_config.yaml` (scorer defaults), 8,192 output tokens | **0.12** |
| 🤖 kozykappa's copy | The same source and a byte-identical `submission.zip`, submitted later | **0.15** |
| 🐈‍⬛ Black Cat v2 · first strike | One agent, default budget | 0.06 |
| 🐈‍⬛ Black Cat v5 · compact | One agent, 4 min · 24 calls | 0.08 |
| 🐈‍⬛ Black Cat v6 · analyzer ("anchor") | Coder + analyzer, 5 min · 40 calls | **0.10** (twice, byte-identical archive) |
| 🐈‍⬛ Black Cat "lab-tuned" | One lean agent, temperature 1.0, many lab-derived rules | 0.06 |
| 🐈‍⬛ Black Cat v8 · Pack Instinct | Anchor design + top-bundle budget + long list of lab-derived rules | 0.05 |
| 🧭 Pathfinder v1 | Coder + analyzer, short data-driven prompts, **hard 4-minute self-limit** | 0.08 |

### What the evidence supports

1. **The score is noisy.** The same archive scored 0.10 and 0.10 (Black Cat), while the same top bundle scored 0.12 and 0.15. A swing of about **0.03** is a few tasks. (The sources disagree on the hidden-set size, about 60 in one and about 120 in the other, so treat "a few tasks" as the safe wording.) One submission can only detect a *large* effect.
2. **A short, generic prompt beat long rule lists.** Black Cat's v8 used the same budget and token limit as the top bundle and still scored 0.05. The remaining difference was a long list of rules distilled from four public repositories. Every rule matched a real failure, but together they seem to have cost more on the hidden repositories than they saved.
3. **Hard time caps hurt.** Both Pathfinder v1 (4-minute self-limit) and Black Cat v5 (4 minutes, 24 calls) landed at 0.08. Cutting hard tasks short costs more than it saves.
4. **The analyzer should receive the full issue.** A navigator cannot find what it was not told about.
5. **Hidden reasoning stays out of the context window.** `include_thoughts: false` on every agent, in all the scoring bundles.

The practical consequence drives the whole notebook: **start from the best-evidenced bundle, and change exactly one thing per submission.**

def limited_walk(root, max_depth):
    root = Path(root)
    if not root.exists():
        return
    stack = [(root, 0)]
    while stack:
        d, depth = stack.pop()
        try:
            entries = sorted(os.scandir(d), key=lambda e: e.name)
        except (PermissionError, FileNotFoundError, NotADirectoryError):
            continue
        for e in entries:
            yield Path(e.path)
            if e.is_dir(follow_symlinks=False) and depth < max_depth:
                stack.append((Path(e.path), depth + 1))

def dir_stats(path, max_files=200_000):
    n, size, exts, truncated = 0, 0, Counter(), False
    for dp, _, fns in os.walk(path):
        for f in fns:
            n += 1
            try:
                size += os.path.getsize(os.path.join(dp, f))
            except OSError:
                pass
            name = f.lower()
            exts[".tar.gz" if name.endswith(".tar.gz") else (Path(f).suffix.lower() or "(none)")] += 1
            if n >= max_files:
                truncated = True
                break
        if truncated:
            break
    return n, size, exts, truncated

def readme_lines(pattern, max_hits=3):
    hits = []
    for line in README.splitlines():
        if re.search(pattern, line, flags=re.I) and line.strip():
            hits.append(textwrap.shorten(line.strip(), 170))

    return hits

def detect_context_limit(text):
    pats = [r"max[_ -]?model[_ -]?len\D{0,20}?(\d{1,3}(?:[,_]\d{3})+|\d{4,7})",
            r"context(?:[ -]window|[ -]length|[ -]limit|[ -]ceiling)?\D{0,40}?(\d{1,3}(?:[,_]\d{3})+|\d{4,7})\s*(?:tokens)?"]
    for pat in pats:
        for line in text.splitlines():
            m = re.search(pat, line, flags=re.I)
            if m:
                v = int(re.sub(r"[,_]", "", m.group(1)))
                if 2048 <= v <= 2_000_000:
                    return v, line.strip()
    return None, None

def readme_extensions():
    for line in README.splitlines():
        if re.search(r"allowed|permitted|extension", line, re.I):
            exts = set(re.findall(r"(?<![\w/])\.(yaml|yml|md|txt|py|json|safetensors|bin|toml|jinja|j2)\b", line, re.I))
            if len(exts) >= 3:
                return {"." + e.lower() for e in exts}, line.strip()
    return None, None

def readme_size_limit():
    for line in README.splitlines():
        if re.search(r"size|archive|limit|uncompressed", line, re.I):
            m = re.search(r"(\d+(?:\.\d+)?)\s*(GiB|GB|MiB|MB)\b", line)
            if m:
                mult = {"gib": 1024**3, "gb": 1024**3, "mib": 1024**2, "mb": 1024**2}[m.group(2).lower()]
                return int(float(m.group(1)) * mult), line.strip()
    return None, None

def text_corpus(dirs, max_file_bytes=2_000_000, max_files=4000):
    chunks, n = [], 0
    for d in dirs:
        if not d or not Path(d).exists():

                        chunks.append(p.read_text(encoding="utf-8", errors="ignore")); n += 1
                except OSError:
                    pass
            if n >= max_files:
                break
    return "\n".join(chunks)

### 🔬 A real unified-diff parser
Reference patches use plain `--- a/` / `+++ b/` headers, **often without** a `diff --git` line, so counting `diff --git` lines reports "1 file" for every task. This parser tracks hunk line counts and handles both styles. It also detects malformed diffs, which is useful later for checking your agent's own output.

# CELL 19 code
HUNK_RE = re.compile(r"^@@ -(\d+)(?:,(\d+))? \+(\d+)(?:,(\d+))? @@(.*)$")
SYMBOL_RE = re.compile(r"(?:async\s+)?(?:def|class)\s+([A-Za-z_]\w*)")

def _clean_path(p):
    p = p.split("\t")[0].strip()
    return p[2:] if p.startswith(("a/", "b/")) else p

def parse_patch(text):
    """Return {'files': [...], 'malformed': int, 'unterminated': bool}. Each file: path, added, deleted, hunks, symbols, status."""
    files, cur, old_path = [], None, None
    rem_old = rem_new = 0
    malformed = 0

    def new_file(path):
        f = {"path": path, "added": 0, "deleted": 0, "hunks": 0, "symbols": set(), "status": "modified", "_hdr": False}
        files.append(f)
        return f

    for line in (text or "").splitlines():
        if rem_old > 0 or rem_new > 0:                          # inside a hunk
            tag = line[:1]
            if tag in ("+", "-"):
                key = "added" if tag == "+" else "deleted"
                cur[key] += 1
                if tag == "+": rem_new -= 1
                else: rem_old -= 1
                m = SYMBOL_RE.match(line[1:].strip())
                if m: cur["symbols"].add(m.group(1))
                continue
            if tag == " " or line == "":
                rem_old -= 1; rem_new -= 1
                continue
            if tag == "\\":
                continue
            malformed += 1
            rem_old = rem_new = 0                                # fall through: treat as header
        if line.startswith("\\"):
            continue
        if line.startswith("diff --git "):
            m = re.match(r"diff --git a/(\S+) b/(\S+)", line)
            cur = new_file(m.group(2) if m else line[11:].strip())
            continue
        if line.startswith("--- "):
            old_path = _clean_path(line[4:])
            continue
        if line.startswith("+++ "):
            new_path = _clean_path(line[4:])
            if cur is None or cur["_hdr"]:
                cur = new_file(new_path)
            cur["_hdr"] = True
            if new_path == "/dev/null":
                cur["path"], cur["status"] = old_path, "deleted"
            else:
                cur["path"] = new_path
                if old_path == "/dev/null":
                    cur["status"] = "added"
            continue
        m = HUNK_RE.match(line)
        if m and cur is not None:
            rem_old = int(m.group(2)) if m.group(2) is not None else 1
            rem_new = int(m.group(4)) if m.group(4) is not None else 1
            cur["hunks"] += 1
            sm = SYMBOL_RE.search(m.group(5) or "")
            if sm: cur["symbols"].add(sm.group(1))
    for f in files:
        f.pop("_hdr", None)
        f["symbols"] = sorted(f["symbols"])
    return {"files": files, "malformed": malformed, "unterminated": rem_old > 0 or rem_new > 0}

def is_test_path(p):
    p = p.lower()
    return bool(re.search(r"(^|/)(tests?|testing)/", p) or re.search(r"(^|/)test_[^/]*\.py$", p) or p.endswith("_test.py") or p.endswith("conftest.py"))

def render_diff(diff, max_lines=70):
    out = []
    for i, line in enumerate((diff or "").splitlines()):
        if i >= max_lines:
            out.append('<span style="color:#5F6368">… truncated …</span>'); break
        if line.startswith("+") and not line.startswith("+++"): style = "color:#137333;background:#E6F4EA"
        elif line.startswith("-") and not line.startswith("---"): style = "color:#C5221F;background:#FCE8E6"
        elif line.startswith("@@"): style = "color:#1A73E8;font-weight:600"
        elif line.startswith(("---", "+++", "diff ")): style = "color:#5F6368;font-weight:600"
        else: style = "color:#202124"
        out.append(f'<span style="{style}">{esc(line) or "&nbsp;"}</span>')
    return ('<pre style="font-size:12px;line-height:1.4;background:#F8F9FA;padding:10px;border-radius:8px;overflow-x:auto;margin:0">'
            + "\n".join(out) + "</pre>")

### 🔬 Is `search_similar_code` worth a tool call?
Tool calls cost time, so it is worth knowing which ones pay off. We **replay the graph tool offline against the reference fixes**.

**Setup.** For each task, the *gold symbols* are the functions and classes the reference patch edits. The *queries* are the identifiers an agent would plausibly search for in the issue text (backticked names, `snake_case`, `CamelCase`, `dotted.paths`). Three strategies race to find a gold symbol:

| Strategy | What it simulates |
|:--|:--|
| 🔵 **Name lookup** | step one of `search_similar_code(name)`: resolve the name to a symbol (exact → suffix → case-insensitive → substring) |
| 🟠 **Embedding top-10** | the full tool: the 10 nearest neighbours of that symbol by cosine similarity |
| 🟢 **Text search top-10** | a grep: rank symbols by how many issue identifiers appear in their source |

The replay follows the tool as described in the README; it approximates the real implementation rather than reproducing it. Gold symbols only cover edits *inside* an existing function or class, so fixes that only add new code are skipped, and the identifier extraction is a heuristic. Read the numbers as a comparison between strategies, not a score prediction.

def issue_symbols(text, k=8):
    text = re.sub(r"<!--.*?-->", " ", text or "", flags=re.S)
    raw = re.findall(r"`([^`\n]{2,80})`", text)
    raw += re.findall(r"\b[A-Za-z_]\w*(?:\.[A-Za-z_]\w*)+\b", text)
    raw += re.findall(r"\b[a-z]+_[a-z0-9_]+\b", text)
    raw += re.findall(r"\b[A-Z][a-z0-9]+(?:[A-Z][a-z0-9]*)+\b", text)
    out = []
    for r in raw:
        m = re.match(r"\s*([A-Za-z_][\w.]*)", r)
        if not m:
            continue
        s = m.group(1).strip(".")
        if len(s) >= 4 and s.lower() not in STOP and not s.startswith(("http", "www")) and s not in out:
            out.append(s)
    return out[:k]

def gold_symbols(task, by_last):
    gold = set()
    for f in parse_patch(task.get("patch"))["files"]:
        if is_test_path(f["path"]) or not f["path"].endswith(".py"):
            continue
        stem = Path(f["path"]).stem
        for sym in f["symbols"]:
            for nid in by_last.get(sym, []):
                if stem == "__init__" or stem in re.split(r"[./]", nid):
                    gold.add(nid)
    return gold

class SymbolIndex:
    def __init__(self, keys, mat):
        self.keys, self.pos, self.lower = keys, {k: i for i, k in enumerate(keys)}, {}
        for k in keys:
            self.lower.setdefault(k.lower(), k)
        self.unit = mat / np.maximum(np.linalg.norm(mat, axis=1, keepdims=True), 1e-8)

    def resolve(self, q):
        if q in self.pos:
            return q
        suffix = [k for k in self.keys if k.endswith("." + q) or k.endswith("/" + q)]
        if suffix:
            return min(suffix, key=len)
        if q.lower() in self.lower:
            return self.lower[q.lower()]
        sub = [k for k in self.keys if q.lower() in k.lower()]
        return min(sub, key=len) if sub else None

    def neighbours(self, node, k=10):
        sims = self.unit @ self.unit[self.pos[node]]
        return [self.keys[i] for i in np.argsort(-sims)[: k + 1] if self.keys[i] != node][:k]

# 🎯 7. Localization baseline: can plain retrieval find the file?
Before spending GPU time on an agent, measure the difficulty of step 1. For each task we index every non-test `.py` file of the repository snapshot with **TF-IDF over code-aware tokens** (`get_request_handler` → `get request handler`, `CamelCase` → `camel case`) and rank files against the issue text.

- **TF-IDF**: pure lexical similarity.
- **TF-IDF + mention boost**: extra score when the issue explicitly names the file/module or a symbol *defined* in the file. This is what a disciplined `grep` step gives an agent.

**Hit@k** = share of tasks where a gold source file is in the top-k. A low Hit@5 means the agent needs real exploration (analyzer sub-agent, graph tools), not just reading the top result.

_ID_RE = re.compile(r"[A-Za-z_][A-Za-z0-9_]+")
_PART_RE = re.compile(r"[A-Z]?[a-z]+|[A-Z]+(?![a-z])|\d+")
_DEF_RE = re.compile(r"^\s*(?:async\s+)?(?:def|class)\s+([A-Za-z_]\w*)", re.M)

def code_tokens(text):
    out = []
    for tok in _ID_RE.findall(text):
        out.append(tok.lower())
        parts = [p.lower() for p in _PART_RE.findall(tok) if len(p) > 1]
        if len(parts) > 1:
            out.extend(parts)
    return out

def strip_common_prefix(files):
    keys = list(files)
    if len(keys) > 1 and len({k.split("/", 1)[0] for k in keys}) == 1 and all("/" in k for k in keys):
        return strip_common_prefix({k.split("/", 1)[1]: v for k, v in files.items()})
    return files

def read_py_files(entry, max_files=8000, max_bytes=400_000):
    files = {}
    if entry.is_dir():
        for p in entry.rglob("*.py"):
            try:
                if p.stat().st_size <= max_bytes:
                    files[str(p.relative_to(entry))] = p.read_text(encoding="utf-8", errors="ignore")
            except OSError:
                pass
            if len(files) >= max_files:
                break
    elif zipfile.is_zipfile(entry):
        with zipfile.ZipFile(entry) as z:
            for i in z.infolist():
                if i.filename.endswith(".py") and i.file_size <= max_bytes and len(files) < max_files:
                    files[i.filename] = z.read(i).decode("utf-8", "ignore")
    elif tarfile.is_tarfile(entry):
        with tarfile.open(entry) as t:
            for m in t:
                if m.isfile() and m.name.endswith(".py") and m.size <= max_bytes and len(files) < max_files:
                    files[m.name] = t.extractfile(m).read().decode("utf-8", "ignore")
    return strip_common_prefix(files)

def resolve_snapshot(row):
    base = DATA_DIR / "snapshots" if DATA_DIR else None
    if not base or not base.exists():
        return None
    entries = list(limited_walk(base, 1))
    repo = str(row["repo"])
    for key in [row["instance_id"], str(row["base_commit"])[:12], str(row["base_commit"])[:7], repo.replace("/", "__"), repo.split("/")[-1]]:
        if key and len(key) >= 4:
            hits = [p for p in entries if key in p.name]

_INDEX_CACHE = {}
def build_index(entry):
    if entry not in _INDEX_CACHE:
        files = {k: v for k, v in read_py_files(entry).items() if not is_test_path(k)}
        paths = sorted(files)
        if not paths:
            _INDEX_CACHE[entry] = None
        else:
            docs = [(" ".join([p.replace("/", " ")] * 3)) + "\n" + files[p][:200_000] for p in paths]
            vec = TfidfVectorizer(tokenizer=code_tokens, lowercase=False, token_pattern=None, sublinear_tf=True, max_features=300_000)
            _INDEX_CACHE[entry] = (paths, vec, vec.fit_transform(docs), [set(_DEF_RE.findall(files[p])) for p in paths])
        if len(_INDEX_CACHE) > 6:
            _INDEX_CACHE.pop(next(iter(_INDEX_CACHE)))
    return _INDEX_CACHE[entry]

def rank_files(index, query, boost=False):
    paths, vec, X, defs = index
    scores = (X @ vec.transform([query]).T).toarray().ravel()
    if boost:
        q = query.lower()
        q_ids = {t for t in _ID_RE.findall(query) if len(t) >= 4 and ("_" in t or any(c.isupper() for c in t[1:]))}
        for i, p in enumerate(paths):
            stem = Path(p).stem.lower()
            if len(stem) >= 4 and stem not in GENERIC_STEMS and re.search(r"(?<![\w/])" + re.escape(stem) + r"(?![\w])", q):
                scores[i] += 0.5
            if p.lower() in q:
                scores[i] += 1.0
            scores[i] += 0.3 * len(defs[i] & q_ids)
    return [paths[i] for i in np.argsort(-scores, kind="stable")]

def file_hit(ranked, gold, k):
    top = ranked[:k]
    return any(p == g or p.endswith("/" + g) or g.endswith("/" + p) for p in top for g in gold)

# ✂️ 8. Edit mechanics & patch safety
### A string-replacement `edit_file`, simulated
Agents lose a lot of turns to failed or *silently broken* edits. The simulator below re-implements the common three-tier strategy (**exact → whitespace-flexible → token regex**) and, crucially, **checks that the result still parses**. It is a local model for building intuition; the real harness implementation is authoritative.

# CELL 37 code
def simulate_edit(content, old, new):
    """Return (new_content | None, tier, error | None)."""
    c = content.count(old) if old else 0
    if c == 1:
        return content.replace(old, new), "exact", None
    if c > 1:
        return None, "exact", f"old_string matches {c} times, so it must be unique"
    lines = content.split("\n")
    target = [l.strip() for l in old.strip("\n").split("\n")]
    if any(target):
        hits = [i for i in range(len(lines) - len(target) + 1) if all(lines[i + j].strip() == target[j] for j in range(len(target)))]
        if len(hits) == 1:
            i = hits[0]
            indent = lines[i][: len(lines[i]) - len(lines[i].lstrip())]
            block = [(indent + l) if l.strip() else "" for l in textwrap.dedent(new.strip("\n")).split("\n")]
            return "\n".join(lines[:i] + block + lines[i + len(target):]), "flexible", None
        if len(hits) > 1:
            return None, "flexible", f"{len(hits)} whitespace-insensitive matches"
    toks = old.split()
    if toks:
        ms = list(re.finditer(r"\s+".join(map(re.escape, toks)), content))
        if len(ms) == 1:
            return content[: ms[0].start()] + new + content[ms[0].end():], "regex", None
        if len(ms) > 1:
            return None, "regex", f"{len(ms)} regex matches"
    return None, "—", "old_string not found"

def compiles(src):
    try:
        ast.parse(src); return True, ""
    except SyntaxError as e:
        return False, f"{type(e).__name__}: {e.msg} (line {e.lineno})"

ORIGINAL = """def calculate_total(items):

        total += item.price

### 🧪 Patch sanity checker
Run this on every patch your agent produces during local experiments. On the reference patches it doubles as a check of the parser itself. It flags empty or corrupted diffs, edits to tests or harness files, leftover scratch files and oversized patches (the "stay small" rule from section 4).

# CELL 39 code
PROTECTED = ("conftest.py", "pytest.ini", "tox.ini", "noxfile.py", "setup.cfg", "pyproject.toml", ".github/")
SCRATCH_RE = re.compile(r"(^|/)(repro|reproduce|scratch|debug|tmp|temp)[^/]*\.py$", re.I)

def check_patch(diff, max_churn=400, soft_churn=60, soft_files=3):
    """Return a list of (severity, message). severity ∈ {'error', 'warn'}."""
    if not diff or not diff.strip():
        return [("error", "empty patch")]
    info, issues = parse_patch(diff), []
    if not info["files"]:
        issues.append(("error", "no file headers found"))
    if info["malformed"] or info["unterminated"]:
        issues.append(("error", "hunk line counts do not match the @@ headers (corrupted diff)"))
    churn = 0
    for f in info["files"]:
        churn += f["added"] + f["deleted"]
        if is_test_path(f["path"]):
            issues.append(("warn", f"modifies a test file: {f['path']}"))
        if any(f["path"].endswith(p) or p in f["path"] for p in PROTECTED):
            issues.append(("warn", f"touches config/harness file: {f['path']}"))
        if f["status"] == "added" and SCRATCH_RE.search(f["path"]):
            issues.append(("error", f"looks like a leftover scratch file: {f['path']}"))
    if churn > max_churn:
        issues.append(("warn", f"very large patch ({churn} changed lines)"))
    elif churn > soft_churn or len(info["files"]) > soft_files:
        issues.append(("warn", f"bigger than most reference fixes ({churn} lines, {len(info['files'])} files): was the issue misread?"))
    return issues

class IncludeLoader(yaml.SafeLoader):
    """SafeLoader that keeps `!include path` as {'__include__': path} so includes can be resolved and validated."""
IncludeLoader.add_constructor("!include", lambda loader, node: {"__include__": loader.construct_scalar(node)})

def resolve_ref(name, ref):
    """`!include` / `config_path` targets: relative to the including file for `!include`, normalised."""
    return posixpath.normpath(posixpath.join(posixpath.dirname(name), ref))

def expand(files, name, obj, problems=None):
    """Recursively replace {'__include__': ref} by the referenced file's (parsed) content."""
    if isinstance(obj, dict) and set(obj) == {"__include__"}:
        target = resolve_ref(name, obj["__include__"])
        if target.startswith("..") or target not in files:
            if problems is not None:
                problems.append(f"{name}: include '{obj['__include__']}' does not resolve inside the bundle")
            return None
        text = files[target]
        if target.endswith((".yaml", ".yml")):
            return expand(files, target, yaml.load(text, Loader=IncludeLoader), problems)
        return text
    if isinstance(obj, dict):
        return {k: expand(files, name, v, problems) for k, v in obj.items()}
    if isinstance(obj, list):
        return [expand(files, name, v, problems) for v in obj]
    return obj

def load_agent(files, name, problems=None):
    return expand(files, name, yaml.load(files[name], Loader=IncludeLoader), problems)

def sub_agent_paths(agent):
    return [t["agent_tool"]["config_path"] for t in agent.get("tools") or [] if isinstance(t, dict) and "agent_tool" in t]

def summarize_bundle(files):
    agent = load_agent(files, "agent.yaml")
    cfg = agent.get("generate_content_config") or {}
    subs = sub_agent_paths(agent)
    sub = load_agent(files, subs[0]) if subs else None
    budget = (yaml.safe_load(files["eval_config.yaml"]) or {}).get("evaluation", {}) if "eval_config.yaml" in files else {}

# 🛡️ 11. Validator & packaging
With one submission a day, a broken bundle costs a full day, so these checks run **before** the zip is written and the build stops on any blocking failure. The allowed extensions and size limit are **parsed from the README when present**, and the source of every limit is shown.

| Check | Why |
|:--|:--|
| exactly one root config, YAML parses | harness requirement |
| every `!include` / `config_path` resolves **inside** the bundle | a missing file fails the whole run |
| single required model alias, matches the sample | multiple models are rejected |
| registered tools only, root can `submit_patch` | an unknown tool breaks the agent |
| **sub-agents are read-only** | an analyzer that edits files pollutes the patch |
| thoughts hidden, `thinking_budget < max_output_tokens`, tokens ≤ 8,192 | the largest value with leaderboard results |
| **no unknown ADK state placeholder** in an instruction | `{name}` is a template variable: an unknown one raises `KeyError` at run time (`{problem_description?}` is the one known-good variable) |
| `eval_config.yaml` only if requested, within limits | the top bundle ships none |
| file types, size, hidden files, adapter config | packaging rules |
| scored profiles match their recorded SHA-256 | proves nothing was changed |

**A note on `..` in includes.** One notebook reports that the README rejects paths containing `..`. Yet the scored top and anchor bundles use `!include ../prompts/analyzer.md` from `sub_agents/code_analyzer.yaml`, and both resolved fine. The validator therefore **fails only on paths that escape the bundle** and shows a notice for `..` that stays inside it. The README lines that mention it are printed below when the data is attached.

WRITE_TOOLS = {"edit_file", "write_file", "submit_patch"}
ADK_PLACEHOLDER = re.compile(r'(?<![\$\{\\]){+[^{}]*}+')      # the pattern ADK uses for state injection
ALLOWED_STATE = {"problem_description"}
sha256 = lambda b: hashlib.sha256(b).hexdigest()

def validate_files(files, profile=None, verbose=True):
    checks = []
    def add(status, name, detail=""):
        checks.append({"status": status, "check": name, "detail": detail})

    roots = [n for n in ROOT_NAMES if n in files]
    add("PASS" if roots == ["agent.yaml"] or len(roots) == 1 else "FAIL", "exactly one root config", ", ".join(roots) or "none found")
    if not roots:
        return pd.DataFrame(checks), False

    problems, agents, notices = [], {}, []
    def collect(name):
        if name in agents:
            return
        agents[name] = load_agent(files, name, problems)
        for sub in sub_agent_paths(agents[name]):
            if sub not in files:
                problems.append(f"{name}: config_path '{sub}' is not in the bundle")
            else:
                collect(sub)
    try:
        collect(roots[0])
    except Exception as e:
        problems.append(f"{type(e).__name__}: {e}")
    for n, t in files.items():
        for ref in re.findall(r"!include\s+(\S+)", t) if n.endswith((".yaml", ".yml")) else []:
            tgt = resolve_ref(n, ref)
            if tgt.startswith("/") or tgt.startswith(".."):
                problems.append(f"{n}: include '{ref}' escapes the bundle")
            elif ".." in Path(ref).parts:
                notices.append(f"{n} → {ref}")
    add("PASS" if not problems else "FAIL", "YAML parses, includes and config_path resolve inside the bundle", "; ".join(problems) or f"{len(agents)} agent(s)")
    add("PASS" if not notices else "WARN", "'..' in includes (stays inside the bundle)", ("used by the scored bundles: " + "; ".join(notices)) if notices else "none")

    models = {a.get("model") for a in agents.values()}
    add("PASS" if len(models) == 1 and None not in models else "FAIL", "single required model", ", ".join(map(str, models)))
    if SAMPLE["models"]:
        add("PASS" if models <= SAMPLE["models"] else "WARN", "model alias matches sample submission", f"sample: {sorted(SAMPLE['models'])}")
    all_tools = {t for a in agents.values() for t in (a.get("tools") or []) if isinstance(t, str)}
    add("PASS" if all_tools <= REGISTERED_TOOLS else "FAIL", "registered tools only", ", ".join(sorted(all_tools - REGISTERED_TOOLS)) or f"{len(all_tools)} tools")
    root_tools = [t for t in agents[roots[0]].get("tools") or [] if isinstance(t, str)]
    add("PASS" if "submit_patch" in root_tools else "FAIL", "root agent can submit_patch")
    for name, a in agents.items():
        if name != roots[0]:
            bad = sorted(set(t for t in a.get("tools") or [] if isinstance(t, str)) & WRITE_TOOLS)
            add("PASS" if not bad else "FAIL", f"{name}: sub-agent is read-only", ", ".join(bad) or "ok")

    for name, a in agents.items():
        cfg = a.get("generate_content_config") or {}
        tc = cfg.get("thinking_config") or {}
        hidden = tc.get("include_thoughts") is False or str(tc.get("thinking_level", "")).upper() == "NONE"
        add("PASS" if hidden else "FAIL", f"{name}: reasoning kept out of context", str(tc))
        mot = cfg.get("max_output_tokens", 16384)
        ok_budget = tc.get("thinking_budget", 0) < mot
        add("PASS" if 1 <= mot <= 8192 and ok_budget else ("WARN" if ok_budget and mot <= 32768 else "FAIL"),
            f"{name}: token limits", f"max_output={mot} (8,192 is the largest value with leaderboard results), thinking_budget={tc.get('thinking_budget', '—')}")
        if mot > 0.35 * CONTEXT_LIMIT:
            add("WARN", f"{name}: output reservation vs context", f"{mot:,} tokens is more than 35% of the {CONTEXT_LIMIT:,}-token window")
        instr = a.get("instruction")
        unknown = []
        if isinstance(instr, str):
            for m in ADK_PLACEHOLDER.finditer(instr):
                var = m.group().strip("{}").strip().removesuffix("?")
                if not var.isidentifier() or var not in ALLOWED_STATE:
                    unknown.append(m.group())
        add("PASS" if not unknown and isinstance(instr, str) else "FAIL", f"{name}: no unknown ADK state placeholders in the instruction", ", ".join(unknown[:5]) or "ok")

    if "eval_config.yaml" in files:
        try:
            b = yaml.safe_load(files["eval_config.yaml"])["evaluation"]
            ok = 0 < b["max_time_minutes"] <= 60 and 0 < b["max_tool_calls"] <= 100
            add("PASS" if ok and CFG["ship_eval_config"] else ("WARN" if ok else "FAIL"), "eval_config.yaml", f"{b} — the top bundle ships none; hard caps scored lower")
        except Exception as e:
            add("FAIL", "eval_config.yaml parses and is within limits", str(e)[:100])
    else:
        add("PASS", "eval_config.yaml absent (scorer defaults)", "same as the top bundle")

    bad_paths = [n for n in files if Path(n).is_absolute() or ".." in Path(n).parts or Path(n).name.startswith(".")]
    bad_ext = [n for n in files if Path(n).suffix not in ALLOWED_EXTS]
    empty = [n for n, t in files.items() if not t.strip()]
    add("PASS" if not (bad_paths or bad_ext or empty) and len(files) <= 10000 else "FAIL", "safe paths, allowed file types, no empty files",
        ", ".join(bad_paths + bad_ext + empty) or f"{len(files)} files · allowed: {', '.join(sorted(ALLOWED_EXTS))}" + ("" if _exts else " (default, unverified)"))
    total = sum(len(t.encode("utf-8")) for t in files.values())
    add("PASS" if total <= MAX_BYTES else "FAIL", "size limit", f"{human_bytes(total)} / {human_bytes(MAX_BYTES)} ({'README' if _size else 'default, unverified'})")
    prompt_tok = sum(est_tokens(t) for n, t in files.items() if n.endswith(".md"))
    add("PASS" if prompt_tok < 0.15 * CONTEXT_LIMIT else "WARN", "prompt size vs context", f"~{prompt_tok:,} tokens across .md files")

    if profile == "top_bundle":
        diffs = [n for n in TOP_BUNDLE_FILE_SHA256 if sha256(files.get(n, "").encode("utf-8")) != TOP_BUNDLE_FILE_SHA256[n]]
        add("PASS" if not diffs and sorted(files) == sorted(TOP_BUNDLE_FILE_SHA256) else "FAIL", "every file matches the published top bundle (SHA-256)", ", ".join(diffs) or "5/5 identical")

    report = pd.DataFrame(checks)
    passed = not (report["status"] == "FAIL").any()
    if verbose:
        style = {"PASS": ("#e7f6ef", "#127a52"), "FAIL": ("#fdeaea", "#b3261e"), "WARN": ("#fdf3e3", "#8a5a00")}
        rows = "".join(f'<tr style="border-top:1px solid #e3e6ea"><td style="text-align:left;padding:6px 10px;width:70px"><span style="background:{style[s][0]};color:{style[s][1]};'
                       f'font-weight:700;padding:2px 10px;border-radius:999px;font-size:12px">{s}</span></td><td style="text-align:left;padding:6px 10px">{esc(c)}</td>'
                       f'<td style="text-align:left;padding:6px 10px;color:{MUTED};font-family:monospace;font-size:12px">{esc(d)}</td></tr>' for s, c, d in report[["status", "check", "detail"]].itertuples(index=False))
        display(HTML(f'<table style="border-collapse:collapse;width:100%;font-size:13px">{rows}</table>'))
        callout("All blocking checks passed." if passed else "Blocking issues found. Fix them before submitting.", "ok" if passed else "err")
    return report, passed

# CELL 56 code
def package(files, output):
    """Deterministic zip: sorted entries, fixed timestamps and permissions → identical bytes for identical bundles."""
    output = Path(output); output.unlink(missing_ok=True)
    with zipfile.ZipFile(output, "w") as archive:
        for name, content in sorted(files.items()):
            info = zipfile.ZipInfo(name, date_time=(1980, 1, 1, 0, 0, 0))
            info.compress_type, info.create_system, info.external_attr = zipfile.ZIP_DEFLATED, 3, 0o644 << 16
            archive.writestr(info, content.encode("utf-8"))
    with zipfile.ZipFile(output) as archive:                              # round trip: validate the archive itself, not the folder
        assert archive.testzip() is None
        back = {n: archive.read(n).decode("utf-8") for n in archive.namelist()}
    assert back == files, "archive content differs from the bundle"
    return output

# 🚀 12. Playbook & experiment log

### The rules of the game
1. **One change per submission.** With about ±0.03 of noise, only a single, local change can be attributed. `CHANGES` in section 10 counts the toggles you changed.
2. **Judge a challenger against your own baseline score**, not against a score quoted in somebody's title (often the best of several submissions).
3. **Promotion rule** (Black Cat): if a challenger scores above the current anchor it becomes the new anchor. A tie, or a one-task miss, is not evidence against it.
4. **Keep the scored fallbacks.** `anchor_submission.zip` and `fallback_submission.zip` are verified against the archives that scored 0.10 and 0.08.

### Ranked next steps (by expected value and evidence)

| # | Idea | Why (evidence) | How in this notebook | Effort |
|:-:|:--|:--|:--|:-:|
| 1 | **Submit `top_bundle` unchanged as your own baseline** | The only configuration with two leaderboard results (0.12, 0.15); every later score is judged against yours | `profile = "top_bundle"` | 🟢 |
| 2 | **Keep `search_similar_code` away from the analyzer** | Its results carry whole class bodies; a context overflow discards the patch (Black Cat). Section 6's replay asks whether it earns its cost | `profile="custom"`, `analyzer_search_similar=False` | 🟢 |
| 3 | **Issue-reading rules** | Data-driven (exact names, PR boilerplate, `docs_src/`), but unscored, and long rule lists hurt before | `profile="custom"`, `issue_rules=True` | 🟢 |
| 4 | **Pass the issue to the analyzer through `{problem_description?}`** instead of the coder retyping it | The anchor does this and the validator knows the placeholder | start from the `anchor` profile files | 🟡 |
| 5 | **Single vs analyzer + coder** | Same prompts and sampling, only the architecture changes | `architecture="single"` | 🟡 |
| 6 | **Thinking budget / level sweep** | Trade speed against quality; the compact fallback used `thinking_level: MEDIUM` with a 2,048 budget | `thinking_budget` | 🟢 |
| 7 | **Reviewer sub-agent** | A read-only agent that inspects `git diff` against the issue before `submit_patch` catches scratch files, test edits and partial fixes (see `check_patch`) | new sub-agent file; must pass the read-only check | 🟡 |
| 8 | **Repository-specific hints** | Hot files (section 5) and per-repo test commands. Keep it tiny: it costs context every turn, and rule piles hurt in v8 | prompt appendix | 🟡 |
| 9 | **LoRA adapter, if the rules allow** | Train on trajectories (tool calls + edits) from repositories **other** than the benchmark ones. Tuning on the public tasks risks overfitting and may conflict with the rules, so read the README first. One source says the harness serves up to 8 adapters: verify | adapter files + `adapter_config.json` (checked by the packager) | 🔴 |

### What the evidence says *not* to do
Long lab-derived rule lists (0.05, 0.06) · hard time caps (0.08 ×2) · temperature 1.0 (0.06) · changing several things at once · trusting a title score.

### 🔧 How to adapt this starter
- **Everything** is controlled from `CFG` (section 1). The scored bundles are plain dictionaries (section 9); the builder in section 10 only applies small, asserted text transformations, so a toggle can never silently do nothing.
- New data format? Extend `load_graph`, `load_embeddings` or `read_py_files`. The rest of the notebook picks it up.
- Validation fails on schema? Compare the root config's top-level keys with the official sample displayed in section 10, and read the README lines printed in section 11.
