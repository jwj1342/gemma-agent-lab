# Complete-epoch SWE LoRA: execution record

Status at 19:21 UTC on October 9: the final corpus is encoded, both 4K memory
probes passed, and the single-GPU preflight completed its optimizer update,
validation and checkpoint saving. Fresh-process recovery is queued before the
complete four-GPU run. Training completion and competition submission are pending. This
report does not claim convergence or a repair-rate improvement.

## Question and comparison

Can standard LoRA improve the required Gemma model's repair actions, graph-tool
arguments and task termination? Compare the unchanged baseline agent with the same
agent using the trained adapter on its root model. Keep generation settings, tools,
per-task budgets, public tasks and the version 29 evaluation runtime fixed.

The corpus mixes upstream successful SWE-smith trajectories with locally executed
graph and terminal component exercises. This first combined candidate cannot
identify the graph component's individual contribution; that needs a later ablation.

will present 33,982 actions and 4,680,468 supervised target tokens.

## Configuration and measured preflight

- Training source: `9550a1ffed6359dcc7bc5c9ebcded6a2325faf65`.
- Required base: `google/gemma-4/Other/gemma-4-31b-it-qat-w4a16-ct/2`.
- Standard LoRA: rank 16, alpha 32, attention and MLP text projections;
  122,429,440 trainable parameters. The base is frozen and dequantized to BF16.
- LR 5e-5, effective four-GPU batch eight actions, two epochs, 5% warmup,
  cosine decay, 4K context, BF16 autocast and gradient checkpointing.
- Training environment: Torch 2.14.1, Transformers 5.18.0, PEFT 0.19.1,
  compressed-tensors 0.17.1, Accelerate 1.14.0; Alliance builds, seed 42.

passed both a 4,096-token context and a 2,038-token assistant target, reserving
Adam moment memory. Peak allocated GPU memory was 67.0 and 70.7 GiB respectively.
One allocator retry was logged during the latter; the backward operation completed.
