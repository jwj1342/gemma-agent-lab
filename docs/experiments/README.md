# Experiment reports

Copy [TEMPLATE.md](TEMPLATE.md) to `<date>-<short-name>.md` and keep the completed report in this
directory. Use the matching `runs/<date>-<short-name>/` for local artifacts. Commit the report and
configuration; keep large files outside Git. Link a private artifact location that teammates can access.

Existing baseline results predate this convention. Their authoritative receipts are indexed in
[resource/manifests/](../../resource/manifests/README.md); do not manufacture retrospective run logs.
